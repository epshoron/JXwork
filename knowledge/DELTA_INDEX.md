## P003 已审特色：与既有机制去重（2026-10-21）

- **新入库的两项具体控制**：[D008](deltas/D008_ast_originality_penalty.md) 的**候选对 Alpha Zoo 最大公共子树惩罚**；[D009](deltas/D009_hypothesis_factor_alignment.md) 的**假设—描述—公式双层评分**。二者为**已讨论认可的特化机制**，不是已证实学术首创。
- **不重复建卡**：Idea/Factor/Eval 反馈循环、角色分工、外部知识记忆沿用 D001/D003/D004 作为架构背景；AST 符号组装与公式复杂度不强行单列创新。与 D002 正向公式先验、D006 主题多样化、P004 FSA 的**作用点**不同；P004 创新评价仍待该篇审批。
- **具体缺口**：结构新≠信号新、Eq. 8 符号方向、约束组合消融难以隔离原创性作用；只在 [P003 IDEAS](../papers/P003/IDEAS.md) 集中描述，不生成重复通用 OOS/交易成本 Delta。

## P004 已审批内容与语义去重（2026-10-21）

- **D010：MCTS + 多维反馈搜索**。风险是相对评价参照随 Alpha Zoo 改变，而树按历史最高得分回传，可能导致搜索路径偏向；**未实证证实**。
- **D011：FSA 高频子树规避**。风险是「高频≠无价值」，回避机制可能错失优质结构的进一步利用；**未实证证实**。
- **作者亲自承认的第三项局限**：LLM 内部知识与生成能力限制新颖性、复杂度和搜索广度；**仅记录在 [P004 评价](../papers/P004/ARCHITECTURE.md)，不重复开 Delta 卡**。
- **严格语义去重已检查**：D010 ≠ D001（路径调度与奖励回传 vs 普通反馈）；D011 ≠ D008（高频模式生成约束 vs 对候选逐对计算最大公共子树惩罚）；D011 ≠ D002（动态负向回避 vs 静态正向公式先验）。三个局限的直接成因分别是**动态历史奖励／外部规避规则／LLM 内部知识边界**，已合并其他同义的多样化表述。
- **不声称首创 MCTS / AST / 子树挖掘**：学术新颖性仍须对照 AutoAlpha 等更早工作。[证据及来源](../papers/P004/PAPER.md)。

**去重上传门禁（强制）**：在新增任何创新、特化不足、研究想法或 Delta 之前，必须按 [严格语义去重规范](../RESEARCH_WRITING_STANDARD.md) **显式比对整个最新知识库**。同义重复则合并，相似机制需说明控制位置及操作的实质差异；**未获批或去重不通过，一律不得上云**。

## P007 已审特色与严格语义去重（2026-10-21）

- **D012** 的具体干预在**公式生成前**：从金融论文文本抽取经济想法并与可用算子结合；D002 是既有公式检索，D006 是固定领域 Agent 提示，D009 是生成后假设一致性评分，故不重复。
- **D013** 的具体干预在**单因子市场奖励 → 生成 LLM 参数**：P005 同样更新生成 LLM，但其奖励针对多轮工具搜索的整个因子池；D007 只进化候选代码，D010 回传 MCTS 搜索树，故不重复。
- **唯一批准的较弱特化风险**：TMB 的组收益最大减最小操作可能放大有限样本噪声；区别 P004 D010 的动态相对 Zoo 评分/最大历史路径回传，**没有证实 AlphaRLM 已发生过拟合**。用户认为风险有些牵强，保留为低置信度待核问题。
- **未批准不入库**：“文献到生成公式可能脱节”与 D009 假设一致性相关，本轮未获批准，不单独入新卡。原始实验表仍待直接核查。[P007](../papers/P007/ARCHITECTURE.md)。

## P008 两项机制与一一对应的特化不足（2026-10-21）

- **D014｜连续种子进化 ↔ Pass@T 局限**：在固定种子 Alpha 的改良轨迹中生成后代、评价、回顾并持续改进。但主要成功判定只要至少一条后代 IR 超过种子即计成功，不能代表具体改善幅度。**P005** 是围绕整个因子池的增删/边际贡献进行多轮 RL，**D007** 是外部固定 LLM 代码变异/交叉；因此批准记录这里的**种子任务状态与训练目标差异**，但不称多轮 Agent 为新发明。
- **D015｜五目标分层奖励 ↔ 消融不足**：Tool Call、Consistency、Exploration、Performance、Streak 共同塑造从种子因子出发的进化策略。Figure 4 主要单独拆除 Exploration/Consistency，其他三项及分层组合算子的独立增益仍待更细实验检验。它不同于 P005 的**池级轨迹奖励**、D013 的**单公式 TMB 奖励**、D010 的**搜索树节点回传**。研究者明确指出**探索与一致性等目标的制衡是设计价值，不是已证实缺点**。
- **实验状态**：官方 ICLR 摘要核实高层结构；公开原文 PDF 摘录/表格转录中的 AlphaEvo500 Pass@3（全奖励 0.65，去探索 0.54，去一致性 0.51）仍待直接逐页核验；不等于回测年化收益。**研究者现已批准两条逐项对应的特化验证不足，非性能失效证据**。
- **严格去重结果**：上述两项分别在**持续进化任务组织**、**轨迹奖励/参数训练信号**施加控制，不与现有卡仅因“多轮/强化学习/多样化”概念重合而拆出重复条目。[详见 P008](../papers/P008/ARCHITECTURE.md)。

## 贡献及不足的审批门槛

每篇先画架构、理解原文；**创新点、特化不足和我们的推论必须先在 LLM 对话中逐项提出，经研究者明确拍板，才更新对应已批准知识卡**。研究 Agent 不得为了凑数量录入一般 OOS、成本、市场变化或套话式过拟合；风险要明确关联某篇的独特设计及可检验证据。完整规范见 [RESEARCH_WRITING_STANDARD.md](../RESEARCH_WRITING_STANDARD.md)。

## 以后比较新论文时怎么用

- **存在完全同等机制**：引用基础机制记录或已批准的旧 Delta；没有特化增量就不创建新 Delta。
- **同一机制但具体改动**：先在对话说明改动与证据；**获批后**在旧卡追加变体（例如提示反馈变为持久记忆），不能把所有变体都称作创新。
- **真正出现不同机制**：**先在对话中给出特化差异及证据，获研究者批准后**才新建卡，并与最相近旧机制对比。
- **证据无法区分**：标待核，不以“看起来更新潮”强行添加。

**项目级目标**：随论文积累，逐渐形成可比较的模块库/机制图谱。研究者确认后，才根据既有机制、论文实证和缺口推导我们的创新方向；当前主要任务仍是理解文献本身。
