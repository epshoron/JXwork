# D003｜成功因子知识库（Main KB）与跨次复用

**审批状态：候选待审，研究者尚未确认机制是否应独立建卡；不能作为已批准的 Delta 基线。**

- **首次入库**：P001（KB-first）
- **机制**：对超过接受标准的因子，KB Updater 保存最佳记录到 Main KB；后续新交易想法启动时可以检索其中的历史有效案例，辅助 LLM 生成。
- **更新对象**：**外部知识库内容与提示上下文**，不是已证实的神经网络权重更新。
- **P001 依据**：[作者公开 README](https://github.com/VMSSON345/Self-Improving-Alpha-Mining-for-Quantitative-Trading-via-Multi-Agent-Large-Language-Models-with-Know)（Main KB、KB Updater、检索 Top-K、IC 阈值）。
- **学术首创性判断**：**不是第一篇提出环境反馈积累 KB**。[QuantAgent (2024)](https://arxiv.org/abs/2402.03755) §3.2 已包含将评测反馈积累入 KB，甚至提出保留成功和失败经验。P001 的具体取舍是保留符合条件的最佳有效因子。
- **客观局限**：过去因子有效≠新的时间/市场仍有效；是否出现重复因子与过度集中，必须查正文与后续实验，不直接断言缺少处理。
- **研究想法状态**：保留失败原因和多样性标签是合理候选，但**并不构成我们的原创方法**，QuantAgent 已有相关做法；需要提出比已有实现更具体的差异才有资格称创新。
- **未来比较字段**：存储成功/失败/所有历史？更新阈值？检索元数据？跨任务、跨市场、跨 regime 的生存周期？有无忘记和去重？
- **后续论文记录**：待新增。

- **判定：并非 P001 Main KB 的同等实现**。CogAlpha 会取表现好/差的候选及评分、理由进入下一轮 Prompt，也维护当前进化种群；原文证据并不足以说明存在 P001 式**跨独立任务、长期可检索的成功因子 Main KB**。
