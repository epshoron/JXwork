# D006｜领域专业 Agent + 提示多样化的结构化探索

- **首次入项目知识库**：P002 · CogAlpha（**KB-first，不等于学术原创**）。
- **研究任务**：让 LLM 对 OHLCV 提出更多元、金融语义相对明确的新因子，而不是只反复写同类公式。
- **输入和先验**：同样的日频 OHLCV；七层主题共 21 个专业生成 Agent（每个 Agent 有研究方向），各自以自然语言 Prompt 约束搜索方向；另有 light/moderate/creative/divergent/concrete 五类引导改写。
- **主要输出**：各主题生成的 Python 因子代码及其解释，再进入统一的质量审查/筛选。
- **控制方式**：任务专门化是预设的 Prompt 角色分工；论文并未证明 Agent 会根据市场表现自动重设计专业分工或自行训练参数。
- **P002 原文依据**：[§3.1 Seven-Level Agent Hierarchy、§3.2 Diversified Guidance](https://arxiv.org/html/2511.18850#S3)，[Appendix A.1/A.2](https://arxiv.org/html/2511.18850#A1)。
- **与 P001 的差异**：P001 D002 是 **WorldQuant 101 显式公式检索 KB**，而 P002 提供**金融研究主题与多样化提示**；它们都引导生成，但**先验的来源和载体不同**，不能因为都叫知识引导而重复并入 D002。P001 D004 的 Writer/Judge 分工也不同于本卡的**21 个生成方向之间的专门化分工**。
- **更早研究/学术创新判断**：多 Agent 专业角色、不同提示表达均非首次出现的新概念；这张卡只记录**CogAlpha 在因子任务中的具体组合**。领域内完全同形先例尚未系统查新，故**学术首创性待核**。
- **已报告的验证**：CogAlpha 附录 B.7 将 G、H 先后加入完整系统的逐步消融，组合后指标改善；这是**累积组合效应**，不证明 21 个主题中每个独立贡献多少，也不证明该机制超越所有既有方法。
- **未解决问题**：实际去同质化有多强？固定主题/Token 预算与动态分配谁更好？主题角色覆盖的实质范围如何量化？
- **未来比较字段**：分工方向从哪里来；Agent 独立生成还是交互辩论；多样化 Prompt 策略；固定/自适应预算；候选多样性和边际 OOS 效用。
- **机制关系**：与 [D002](D002_structured_alpha_prior.md) 同属先验引导的不同实现，与 [D004](D004_role_separation.md) 的职责分离相关，但本卡重点是**探索空间划分**而非审核角色。
