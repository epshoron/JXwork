# D013｜P007：单因子 TMB 市场奖励训练生成 LLM

**审批**：2026-10-21 研究者已认可 **TMB 分组收益差 + 合法性奖励 + DAPO 参数级训练**的具体因子生成机制；并**审慎同意保留一项较弱的、尚未证明的极值估计风险**。

- **要解决的问题**：不仅用 IC 或符号有效性筛选已有候选，而是**直接训练因子生成语言模型**，使新生成公式本身更贴近市场预测目标，兼顾非单调收益关系。
- **输入/反馈**：一条生成的 Alpha 公式与它在历史市场窗口的**可执行/时间合法性**和**分组后的未来平均收益**。
- **核心操作**：把股票按因子值分组，取收益最高组减收益最低组（**TMB：max 组均值 - min 组均值，不要求组位于因子分位两端**）；综合合法性奖励后，用 **DAPO** 对公式生成 LLM 的策略权重做梯度训练。
- **真正更新的对象**：**因子生成策略参数**；不同于仅改变代码候选或搜索 Prompt，部署后的新因子再用下游预测器评估。
- **语义去重结果**：
  - [P005 AlphaPilot](../../papers/P005/README.md) 同样在离线训练更新因子 LLM 权重，故**“会用 RL 训练因子 LLM”已不是 P007 独有的新机制**；区别是 P005 使用**多轮工具交互最终因子池的轨迹级 IC/RankIC 奖励**，D013 是**单个公式的合法性与高低收益分组差训练信号**。
  - [D007（P002）](D007_code_evolution.md) 是固定基础 LLM 的**因子 Python 代码层面种群变异与交叉**，不是参数级奖励更新。
  - [D010（P004）](D010_mcts_multidimensional_search.md) 将指标回传**MCTS 节点/搜索树选择**；D013 的更新对象为**模型生成策略权重**。
  - **结论：独立新卡**，具体区别为**分组非单调收益的单因子训练目标与参数级优化**，不宣称首次发明 DAPO/RL/TMB 的一般思想。
- **研究者谨慎认可的一项较弱特化风险（尚未经实验证实）**：TMB 在有限训练样本上主动取收益**最高组/最低组**可能把偶然极值变成较高训练奖励，未必反映真正稳定的收益结构。**作者消融报告 TMB 对比固定端点奖励回测有优势**，这个风险不能写成它已过拟合或设计失败。研究者提醒此不足有牵强之处，务必低置信度保留。
- **未来核验**：分组均值的置信区间、不同样本长度/分组数量、固定预算与稳定 OOS 的对照，特别检查原始 Table 2 与奖励公式。
- **证据**：[AlphaRLM arXiv:2610.14959](https://arxiv.org/abs/2610.14959)（§3.3–3.4 与 §4 消融）；[P007 ARCHITECTURE](../../papers/P007/ARCHITECTURE.md) 与 [IDEAS](../../papers/P007/IDEAS.md)。
