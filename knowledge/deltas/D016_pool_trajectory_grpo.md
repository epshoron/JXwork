# D016｜P005：因子池边际控制 + 多轮工具轨迹 GRPO 训练

**审批（2026-10-21）**：研究者认可这是 P005 值得重点保留的**具体学习机制组合**。**不是宣称 GRPO / RL 微调 / 池级 Alpha 优化为学术首次提出，也不等于证明策略已学会可迁移的金融能力。** 本轮未审批独立缺点或原创解决方案。

## 机制指纹（输入 → 操作 → 更新对象 → 输出）

- **输入/任务**：交易日可知的市场描述、滚动历史数据、现有/种子因子池与有限公式 DSL；目标是生成和维护**整个因子池**，而不只是提高一个因子的单独 IC。
- **多轮动作与工具**：Qwen3-4B 提出因子表达式并调用 `factor_evaluator`；工具返回可执行性及 IC/RankIC/稳定性等数据指标。**Pool Updater** 根据候选加入或替换后对池级评价的边际变化决定接受、拒绝或替换；更新因子池与后续上下文，形成多轮工具轨迹（论文 §4.2–4.3）。
- **可学习反馈**：在**历史离线训练**中，对同一决策情境采样多条完整探索轨迹；基于最终因子池在后续训练目标窗口上的 **Pool IC/RankIC** 等指标生成轨迹级奖励，以 **GRPO** 优化 LLM 搜索策略参数（§4.4–4.5）。未来目标信息用于离线 reward manager，而**不是测试日供 LLM 直接读取的未来输入**。
- **部署阶段**：模型参数按已训练状态使用，按日多轮执行候选搜索和因子池更新，获得下游选股信号；**每日改因子池不等于每日重新微调模型，更不是自我改写训练算法**。
- **更新层级**：一轮内更新候选/因子池/提示上下文；离线学习更新**LLM 参数**。GRPO 是策略训练算法，**不等同于 LoRA 这种参数高效微调实施方式**；论文材料目前不足以确认采用 LoRA 还是全参数更新。

## 严格语义去重：为何不是已有 D 卡换名

- [D001](D001_nested_feedback.md) / [D003](D003_success_memory.md)：普通环境反馈、外部知识积累，未涉及奖励通过梯度训练生成策略；本卡的训练对象不同。
- [D007](D007_code_evolution.md)：固定 LLM 下变异/交叉候选**代码与种群**；本卡训练 LLM 并按**整池边际贡献**控制成员。
- [D010](D010_mcts_multidimensional_search.md)：反馈更新 **MCTS 节点价值/搜索树**；本卡将完整轨迹奖励用于更新 LLM 参数。
- [D013 / P007](D013_tmb_rl_factor_policy.md)：同属因子生成参数级 RL，**不是“RL 微调首次”**；但 D013 对**单个公式的合法性 + TMB 分组收益差**进行 DAPO 训练，本卡对**多轮工具交互形成的整池**给终端奖励并做 GRPO。
- [D014](D014_seed_conditioned_evolution.md) / [D015 / P008](D015_hierarchical_evolution_reward.md)：同有多轮 RL 参数训练；但 P008 围绕**给定种子因子的连续后代改进**与五目标奖励，而 P005 的任务状态是**每日因子池成员增删/替换**、训练信号是整池最终 IC/RankIC。共享的“多轮工具 RL”不单列新卡。
- **更早文献**：AlphaGen 等已有强化学习优化因子集合，不能以“因子池有 RL”宣称首创；保留 P005 的多轮工具交互、Pool Updater 与训练目标耦合的**具体实现区别**。

**判定**：相对已有库中机制，**新建一张特化机制卡**，而非再创建“GRPO”“工具反馈”“因子多样性”三张重复卡。

## 论文证据与研究边界

- **作者报告**：三次独立运行的滚动测试，在 CSI300 和 CSI500 的平均累计总收益分别为 **42.93%、54.19%**，Sharpe 分别为 **2.46、2.86**；在 CSI300 相同 Qwen3-4B/GRPO/数据/奖励的**单轮 GRPO**对照中，多轮版本累计收益高 **7.31 个百分点**。该对照支持多轮方案的价值，但**不等于无 GRPO 消融**，不能单凭此归因全部增益于参数训练。
- **待验证而未获批的研究问题**：无 GRPO 的同预算对照能否隔离参数学习增益；轨迹终端奖励如何精确分配多轮行动贡献；池级贪心保留是否牺牲互补因子组合。这些**不作为本轮正式批准的特化缺陷/原创想法**。
- **证据身份**：arXiv 预印本的作者方法与历史回测；尚无独立代码/回测复现或系统查新，不表示已有实盘验证。参见 [P005 档案](../../papers/P005/README.md)。
