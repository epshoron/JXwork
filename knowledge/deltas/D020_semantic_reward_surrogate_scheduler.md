# D020｜P010：语义奖励 LightGBM 代理与三路配额调度

**审批状态（2026-10-22）**：研究者认可 **Plan–Reward 经验学习 + 代理评分引导搜索预算分配**及其**独立收益归因尚待充分隔离**这一特化问题。不是学术首次发明代理模型、LightGBM 或探索/利用策略。

## 机制指纹

- **输入**：由 [D019](D019_five_axis_semantic_plan_space.md) 定义的五维语义 Plan，LLM 实现结果，经真实历史数据验证的 **RankIC、RankICIR、时滞敏感度**等构成的奖励，以及累计的 `(Plan, Reward)` 历史；不可修复的实施失败计入零奖励。
- **学习操作**：从语义 ID、类别、范围、成对交互构造特征，使用 **LightGBM 预测未实施 Plan 的期望奖励**；随着反馈累积重新训练该**外部代理模型**，不微调负责写公式的 LLM。
- **控制位置**：每轮把有限 LLM 实现与因子评价预算分给 **结构探索（exploration）**、**代理高分引导（exploitation）**、**优质 Plan 局部语义变异（mutation）**；先冷启动探索，随后按已评价计划数使探索份额逐渐衰减，再以模型估计分配实施机会。
- **输出/更新对象**：新的被优先实现的研究计划、后续预算份额和代理评分器参数；**不是改写评分指标公式本身，也不是对 LLM 做 GRPO/DAPO**。

## 严格语义去重

- [D001](D001_nested_feedback.md)/[D003](D003_success_memory.md)：普通回测反馈与存储经验，没有这里**针对尚未实现的金融语义 Plan 学得奖励预测器并分配搜索配额**的干预位置。
- [D010 / P004](D010_mcts_multidimensional_search.md)：MCTS 节点选择和路径统计回传，控制对象是**因子公式树**；P010 用可监督训练的 LightGBM 对**语义计划**评分并动态配额。
- [D016 / P005](D016_pool_trajectory_grpo.md) 及 [D013 / P007](D013_tmb_rl_factor_policy.md)：借奖励优化**生成 LLM 权重**；P010 **只更新外部代理预测器**。
- [D017 / P009](D017_joint_alpha_metric_evolution.md)：让 LLM **编写/替换候选评价指标代码 `g` 并晋级版本**；P010 的 RankIC/RankICIR/滞后惩罚**奖励定义保持预设**，LightGBM 学习的是**既定奖励的预测值**，没有把指标代码变成搜索对象。
- [D019](D019_five_axis_semantic_plan_space.md) 定义 Plan 搜索载体；**本卡唯一主记录**反馈怎样转化为预算调度，两卡不是不同命名的同一个动作。

**结论**：保留独立机制卡，项目内差异在于**学习的对象、搜索调度位置和预算控制方法**；不宣称通用 surrogate-guided search 为首次发明。

## 对应特化不足②：代理可预测，不等于完整搜索增益已隔离

- **实际证据**：Appendix E 用 12,126 条有效 Plan–Reward 观察（含辅助轨迹，不仅是主实验五次挖掘），按语义唯一键分组切分训练/测试。带成对交互的 LightGBM 在 held-out 得到 **Spearman 0.239、Pearson 0.250、Top10% lift 1.519×**，优于打乱奖励对照；这支持语义得分**存在一定可预测性**，但预测相关仍有限。
- **归因缺口**：仅证明代理模型对未见 Plan 的奖励排序有一定预测能力，不自动证明**含三路调度的完整因子挖掘**优于等预算纯探索、无代理或无局部变异；尚需固定 LLM、候选数、验证成本、数据时间切分，独立开关 surrogate 与预算调度。
- **身份**：这是**对原文证据覆盖范围的审慎质疑**，不是已经实证证明调度器失效或出现过拟合。
