# D011｜P004：FSA 高频公式子树规避

**审批状态（2026-10-21）**：研究者确认记录这一特化机制与对应待验证风险；**不等于学术首创认定或缺陷实证**。

**机制**：从动态更新的**有效因子 Alpha Zoo**挖掘高频的公式子树（root genes，抽象参数值），形成应规避的子结构集合，指导 LLM 后续尽量不生成包含这些结构的公式。**控制点在生成前的约束**，不只是最终候选的相似度检查。

**与既有机制的精确区别**：
- [D008 / P003](D008_ast_originality_penalty.md)：**新候选与参考因子逐对计算最大公共子树相似度，作为原创性惩罚**。
- **D011 / P004**：**先从有效因子总体发现高频子树，作为未来生成时要求尽量避开的提示规则**。两者都用了公式树，但统计对象、控制阶段、惩罚方式不相同；不再另设“AST 公式去重”总卡。
- [D002 / P001](D002_structured_alpha_prior.md) 是 WQ101 **正向检索先验**；[D006 / P002](D006_domain_guidance.md) 是主题/提示引导。FSA 则是动态产生的**负向结构约束**。
- 原文明确由 [AutoAlpha (2020)](https://arxiv.org/abs/2002.08245) 的 root gene 概念启发，**不宣称首次发明子树技术**。

**特化不足（已讨论批准为待验证风险）**：**高频不等于无价值**。某高频公式结构可能持续提供有用的金融预测信息，显式要求规避它可能错过对高价值结构进一步组合的机会。需比较高频结构的边际信息、软/硬约束效果；**尚未证实 P004 确实误伤有效结构**。

**与作者 Limitations 的区别**：本文作者还承认**LLM 自身知识与生成能力限制公式新颖性**（Appendix J）；那是模型本身的候选空间边界，而这里是**外加 FSA 禁用规则**的潜在副作用。后者为本卡风险，前者只保留在 [P004 单篇档案](../../papers/P004/ARCHITECTURE.md)，不重复另建一张 Delta。

**证据**：[P004 原文 §3 Frequent Subtree Avoidance（公式 11–12）及 Appendix J](https://arxiv.org/html/2505.11122) · [P004 审批档案](../../papers/P004/ARCHITECTURE.md)。
