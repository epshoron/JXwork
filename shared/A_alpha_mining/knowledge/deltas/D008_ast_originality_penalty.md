# D008｜P003：AST 最大公共子树原创性惩罚

**审批状态（2026-10-21）**：研究者认可 P003 的该项**特化机制及其待核风险**；**不表示该机制为学术首次，也不代表独立实验证实有效**。

- **问题与位置**：避免 LLM 反复生成结构近似的常见因子；控制发生在 **Factor Agent 的生成质量约束**，而非最终投资决策。
- **输入/操作/输出**：将新候选公式及参考 Alpha Zoo 中的因子解析为 AST，依 Eq. 5–6 求候选与每个参考因子的**最大公共子树大小**，取最大相似度作为原创性惩罚，影响后续候选保留/修改。
- **与已有卡的去重关系**：[D002 / P001](D002_structured_alpha_prior.md) 用 WorldQuant 101 **正向检索引导生成**；本卡 P003 用已有公式**作为相似度惩罚参照**。两者共享既有公式知识，但控制方向不同，故独立建卡；不再为“用了 AST”单独开卡。[D006 / P002](D006_domain_guidance.md) 的**主题 Prompt 多样化**是另一种生成引导，同样担心同质化，但风险根源不同。
- **与 P004 的边界**：[P004 已归档的 FSA](../../papers/P004/README.md) 从已收录因子发现**高频子结构**并避免在后续生成中重复；P003 的测量对象是**候选对参考库的最大公共子树相似度**。可视作相关的结构去重设计，但不是同一规则；**P004 特色机制未获审定，不在此代其批准 Delta**。
- **已报告证据**：P003 原文 Figure 6 的约束组合使 hit ratio **0.16 → 0.29**，**未单独消融 AST 原创性项**。Figure 5 观察的 IC 分布差异也不能直接充当因子信号独立性的证明。
- **研究者认可的特化疑问**：**结构原创≠新增 Alpha 信息**；完全不同的表达式树仍可能输出高度相关的股票信号。需检验 AST 差异与信号相关性、边际 IC / 边际组合收益的关系，并仅开关这一项测其对衰减的实际贡献。
- **更新层级**：候选公式与生成约束；没有 LLM 参数更新证据。
- **学术边界**：符号树、公共子树比较、复杂度惩罚均有技术先例；本卡记录 P003 对因子原创性的**具体约束方式**，不是确立“首次发明 AST 去重”。
