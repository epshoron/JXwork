## 21 个专业 Agent 生成的，真的是不同的 Alpha 吗？

**具体机制**：CogAlpha 预设七组 21 个金融研究方向，每个方向再用五类 Prompt 引导独立生成候选。

**经研究者认可、待验证的风险**：不同主题 Prompt 可能生成计算形式不同、但信号高度相关的因子。即使报告“生成了更多因子”，也未必真拓展了**独立预测信息**的覆盖范围。

**真正值得追问**：专业化分工改善的到底是**生成数量、评分指标**，还是**新的、互补的 Alpha**？

**以后核查**：等量 LLM 调用预算下，比较因子的结构/输出相关性、重复率、组合边际贡献，以及使用未参与搜索的数据进行评估的效果；确认论文原文是否已经提供此类去同质化证据。

**证据等级**：2026-10-21 用户明确同意纳入的**特化风险假设**，不是论文实证已揭示的缺陷，也不是我们完成查新的原创技术方案。

此前草稿提出过动态 Agent 预算、长期失败记忆、信息可用时间检查、迭代选择偏差等观点。**这些尚未经研究者逐项审核，暂不纳入此正式档案**；留在 LLM 讨论中，后续逐项判断是否足够特化、有证据支撑且值得记录。
