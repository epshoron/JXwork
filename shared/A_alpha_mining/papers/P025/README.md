# P025｜Information-Theoretic Metric Learning（ITML）

- **来源**：Davis, Kulis, Jain, Sra & Dhillon，ICML 2007。原文研究**学习距离函数**，不是股票 Alpha 搜索或 LLM 金融概念空间的实证。
- **方法骨架**：给定样本对的“应相似/应不相似”等约束，学习 Mahalanobis 距离；用 LogDet divergence 使学习出的距离与初始先验不要偏离过大。
- **核心变量**：正半定度量矩阵以及相似/不相似对约束；可以有初始距离先验，支持在线形式。
- **实验边界**：作者在标准数据集和软件错误报告等任务评价。不能推导为“只要投影金融文本就一定学出可靠金融机制坐标”。
- **核验状态**：已核公开研究机构摘要/原始出处，**未重现原文算法或逐节审查全文**。
- **批准边界**：只有客观方法资料；项目设计、创新、特化缺点及 Delta 未经研究者审批。
