# P007｜TMB 极端分组奖励的稳定性：已认可的特化研究疑问

[架构与实验事实](README.md) · [已确认的贡献与风险边界](ARCHITECTURE.md)

## 问题是什么？

**AlphaRLM 特定设计**：按因子分位分组后，TMB 奖励取未来平均收益**最高组 - 最低组**的差值，而不是预先固定比较因子值最大的组与最小的组。

**研究者审慎认可的风险假设**：在回测窗口样本有限、分组均值受噪声影响时，“挑最大和最小”可能对偶然出现的极端历史差距给出高奖励；若模型根据这种结果更新参数，可能反复偏好偶然极端的公式。

**为何不是已证实缺陷**：作者的 TMB 消融在部分回测指标上确有优势，且我们未验证其出现了真实的收益极值过拟合。研究者特别提醒这个缺点也有些牵强；所以仅作为**较弱的待验证问题**保留，不断言实际发生。

**如何更严谨地检验**：固定训练预算和下游预测器，对比 TMB/固定端点/收益差的置信度校正；看训练窗口长度与分组数量变化下“最大收益差”是否稳定，以及没有用作 RL 奖励的数据上的表现。以上是**未来验证设计的说明，并未获批为我们的原创研究方案**。

**严格去重结论**：与 [P001/D002](../../knowledge/deltas/D002_structured_alpha_prior.md) 的经典公式先验收缩、[P002/D006](../../knowledge/deltas/D006_domain_guidance.md) 的 Agent 间因子同质化、[P004/D010](../../knowledge/deltas/D010_mcts_multidimensional_search.md) 的动态 Zoo 评价/历史最大值回传不同；这里的失效原因是**单一候选的分组收益计算在历史样本中主动取最大/最小组**。不重复录入“凡是回测都可能过拟合”的通用风险。

**原文/数据边界**：[AlphaRLM arXiv](https://arxiv.org/abs/2610.14959)，数值仍待原始 PDF 实验表直接核验。论文合法性奖励、LEGO 文献构造等结构事实不强行另配不足。

**本轮审批结果（2026-10-21）**：**两项特色贡献 + 此一项审慎记录的风险**；“文献到公式可能脱节”暂不保留为本篇正式特化不足。
