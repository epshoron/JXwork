# P020｜原文来源与核验边界

- **标题**：Robust performance hypothesis testing with the Sharpe ratio
- **作者**：Oliver Ledoit, Michael Wolf
- **期刊**：*Journal of Empirical Finance* 15(5), 850–859 (2008)
- **DOI**：[10.1016/j.jempfin.2008.03.002](https://doi.org/10.1016/j.jempfin.2008.03.002)
- **出版社摘要**：[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S0927539808000182)
- **作者论文入口**：[原稿 PDF（只链接）](https://www.ledoit.net/Robust_Sharpe_2008.pdf)
- **本轮核验**：正式出处与摘要，尤其是厚尾/序列依赖、studentized time-series bootstrap Sharpe 差置信区间、以是否包含 0 判断差异。
- **未核**：全文公式逐项推导及其具体金融时间序列实现、同一训练集生成大量候选后的 post-selection inference。不能据此直接批准替换阈值或宣称公司系统有效。
- **审批/版权**：客观来源骨架入档；独立项目评价/方法增量未获研究者批准；未复制 PDF。
