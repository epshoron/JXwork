# P026｜DreamCoder：从已解程序学习可复用的抽象库

- **来源**：Ellis et al.，PLDI 2021（ACM SIGPLAN）。研究归纳式程序合成，不是金融因子自动挖掘论文。
- **问题**：除了通过已有组件搜索程序，系统能否从历史解答中学习更高阶的可复用组件，使未来问题的表示和搜索更容易？
- **原文方法骨架**：输入多个程序合成问题及少量例子；Wake 阶段搜索可用程序；Sleep / library learning 阶段利用 E-graph matching/refactoring 压缩并抽取跨程序共同子结构，并训练引导新程序搜索的模型；语言库和搜索策略互相促进。
- **原文作者报告**：在规划、逆向图形、方程发现等八类领域中，逐步抽象提高可解任务数和搜索效率；**无分钟金融因子、回测费用或三库验证**。
- **边界**：已有算子库≠自动抽象学习，但自动学习若只压缩重复代码也可能没有新增预测信息。此处不提出项目级机制、创新或增量结论。
