# P028｜Enhanced POET：问题环境与求解者共同演化

- **来源**：Wang et al.，ICML 2020。研究开放式强化学习任务，不是金融因子挖掘或可生成真实金融市场状态的证据。
- **原文核心**：不仅改进当前求解者（policy/agent），也持续创造新的、具有一定难度且有意义的环境挑战；为每个环境保留求解者，并在任务/环境之间测试求解者迁移与互换，以跨越局部最优。
- **机制位置**：环境/任务空间**与**求解方案空间共同演化；与仅在固定评价目标下变异程序不同。作者介绍了新颖挑战度量与代理切换启发式。
- **作者验证**：在开放式控制环境中观察到复杂行为生成；**不能等同于在观察性金融数据中能生成合法的新市场状态**。
- **关键边界**：在金融研究中任何环境生成都必须尊重真实历史的可观测性、时间信息和交易可达性；不能用任意合成路径冒充真实 Alpha 证据。

本条仅归档客观论文材料，**没有审批项目创新、具体研究提案或 Delta**。
