# P027｜Hyperband：多保真、逐级分配验证预算

- **来源**：Li, Jamieson, DeSalvo, Rostamizadeh & Talwalkar，JMLR 18(185), 2018。研究多配置超参数优化，不是金融回测或自动发现经济机制。
- **方法问题**：当每个候选完整评价都昂贵，而部分评价可较廉价给出近似指示时，怎样将固定计算预算分配到更多候选与更深验证之间？
- **原文机制**：Successive Halving 给大量候选较少资源，淘汰部分候选，为留下者增加资源；Hyperband 在不同起始候选数与单候选资源分配间使用不同 bracket，缓解单一资源安排的局限。
- **作者报告**：在多种深度学习和核方法超参实验中表现出显著预算效率优势；它不证明金融样本短窗评分与完整长窗评分一致。
- **适用限制**：若小规模早期结果与最终评估相关性弱，过早淘汰会错失优秀候选；用户系统如何定义有效忠实的低保真评价，必须单独实证。

只记录客观机制；项目级方案、创新/不足和 Delta 未经审批。
