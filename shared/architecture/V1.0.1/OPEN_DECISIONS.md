# V1.0.1｜仍需冻结的工程口径（2026-10-29）

> **本文件记录未定项，不更改已经拍板的准入规则。** 公司电脑可以先实现接口与模拟数据测试，但真实数据自动运行之前必须固定所有 P0 项。任何未知统计量不得伪造 PASS。

## 已确认的规则（不必重新讨论）

- 四个逻辑库：Min、论文/研报、Daily、Knowledge。所有候选与成功/失败实验都保留在同一 Knowledge，成功者通过 `qualified` 筛选，不建 Alpha 第五库。
- Alpha 流程：技术/未来信息硬关 → Statistical Evaluator → Financial Evaluator；上一阶段 FAIL/BLOCKED 不进入下一评价。
- Alpha 的相关性只与 Knowledge 中已成功且内部真实执行的胜者比较，最大绝对相关性严格 `<0.65`，等于 0.65 失败。首个无成功参照时只跳过此项。
- Daily 的独立准入相关性 `<0.6`；Alpha 真正成功：通过各关后 `ret_ann_gross>0.03` 且 `sr_gross>1`。Score 可随时按指标重新计算，不作为成功判定依据。

## 待确定事项

| 优先级 | 事项 | 具体待定问题 |
|---|---|---|
| P0 | Alpha 相关计算口径 | Pearson/Spearman；逐日横截面平均还是全期拼接；样本重叠、零方差与缺失值处理 |
| P0 | Alpha 参照样本 | 跨股票池/市场、数据版本及回测窗口的成功者如何比较；胜者数较大时怎样保证可复现 |
| P0 | Daily 相关计算口径 | 是否使用绝对值、相关系数种类、同样的样本聚合与最小样本规则；首个 Daily 特征无参照时如何处理 |
| P0 | Ret 3% 收益解释 | 现行 Evaluator 是年化毛收益；老师要求的 3% 是毛还是净？应当怎样使用样本外数据、评测窗口与实际时点 |
| P0 | 真实数据、股票池和交易限制 | Min 实际字段、交易日、停复牌、缺失、新股、可交易股票池、数据许可；检查 VWAP 时间对齐 |
| P1 | 统计质量默认阈值 | 除相关性以外的最低覆盖率/有效样本、异常值、常数、极端值及严格重复的判断规则 |
| P1 | 并发与成功快照 | 多 Agent 同时测试时，需要在正式 `qualified=true` 前对最新胜者集合重新检查，以免同时看到空集合；实现锁或版本校验 |
| P1 | 工程管理 | CSV 版本/分区/原子写、数据库技术、失败重试、**当前16角色每轮抽样/预算（角色数已采用、最优性未验证）**、Full/Masked 实验比例与遗传触发 |

## 第一轮本地验收建议

用合成数据测试：初始成功胜者集合为空时，第一位 Alpha 仍完整接受合法性和金融评测；后续 Alpha 相关性等于 0.65 或更高时不能进入 Financial Evaluator；金融评测失败仍保存 Ret/SR/DD/TO；成功者自动成为后继参照；Score 不影响 `qualified`。所有阻断状态与使用的胜者 ID/版本可追溯。
