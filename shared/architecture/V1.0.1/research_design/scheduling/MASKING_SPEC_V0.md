# Full / Masked｜生成期研究结论遮蔽机制 V0

## 1. 遮蔽对象

**full**：在本轮授权与固定 Knowledge 快照内，允许检索全部可读的结构化研究卡、历史Alpha定义和真实实验卡。外部作者结果与内部执行结果始终保留来源身份。

**masked**：仅在 **M3 Alpha 生成阶段**，对已存在的 **Alpha研究结论／同一假设谱系** 分组后可复现随机隐藏。默认一个被遮蔽的 group 包含同一结论的候选公式、已报告表现、衍生版本、内部成败结果及能直接暴露这些结论的摘要。不能只遮蔽“盈利好”的因子，也不能按未来收益选择遮蔽组。

始终可见：已确认的原始Min字段、数据权限和时间规则、已发布Daily特征的**真实定义／依赖／可用时点**、现行研究环境和工具安全要求、评价口径、知识源索引中不泄漏具体结论的客观条目。Masked**不是**随机删数据字段、删除Daily基础结构、向模型给假的资料或禁止模型自主研究。

## 2. 分组与版本

M2/Knowledge所有者提供已存在的研究卡关系与稳定ID，由编排侧建立 `mask_group_index_version`。分组按**同一研究结论及其直接演化／谱系**，包括明显等价公式、同一Alpha父子链与直接引用的结论；**不能**仅因为两篇材料都引用同一本书就合成一个巨组。不同历史实验指向同一Alpha结论时应处于同组。

分组是原有Knowledge记录的**只读索引/视图**，不是新库。组间连接、来源引用、衍生摘要等也需按是否揭露被遮蔽结果进行过滤。若关系缺失且无法保证一个结论没有分散到多组，应拒绝开展正式masked可比性实验，保留 full 模式供调试；不得把不完整分组伪装成成功遮蔽。

## 3. 可复现抽样（建议V0算法）

输入：`knowledge_snapshot_id`, `mask_group_index_version`, `mask_seed`, `mask_probability` （0至1，**由实验配置给出；当前无拍板默认值**）。

对快照内每个已确定的唯一 `group_id`，计算：

```text
key = canonical_json(["mask-v0", knowledge_snapshot_id,
                      mask_group_index_version, mask_seed, group_id])
u = int(SHA256(UTF8(key))[0:13], 16) / (16 ** 13)
hidden(group_id) = (u < mask_probability)
```

这里取 SHA256 十六进制的前13位即52bit，避免依赖不同语言的随机数库实现。0意味着无组被遮蔽，1意味着全部可遮蔽组被遮蔽。**不强制恰好遮蔽某个固定数量；也不强制至少遮蔽一组**，真实遮蔽数应记录。组分配与随机抽样必须在**模型启动前**完成，禁止依照生成结果事后修改。

产出 `exposure_view_id`、固定的 `visible_group_ids` / `hidden_group_ids`（后者仅内部审计可见）、策略版本与哈希；Research Agent 只获得可见视图和普通研究材料，不接收隐藏组清单。

## 4. 查询过滤必须生效的地方

同一个 `exposure_view_id` 绑定本轮 M2 研究查询令牌，所有知识接口统一生效：

| 入口 | masked下的行为 |
|---|---|
| 初始知识卡摘要/分页 | 过滤隐藏结论组及其结果、摘要 |
| Knowledge关键词/向量检索 | 搜索阶段就排除隐藏组，排序、结果总数和展开都不能暴露隐藏命中 |
| Factor/Experiment ID点查 | 检查组权限，隐藏结果不得以直接ID访问绕过 |
| 关系与谱系查询 | 不展示指向隐藏结果的公式、父代或实验结论等敏感连接 |
| 论文索引和按章节读取 | 保留不泄漏的客观元信息；涉及被遮蔽结论的原文段落由策略过滤，或进入明确记录的“事实核验解遮蔽”路径 |
| Min/Daily字段及定义目录 | 保持完整可见且时点正确；不得因mask破坏可计算依赖 |
| 生成后的M4/M5技术统计检查 | **完全恢复全量真实Knowledge**；不得用masked视图做最终重复和胜者相关性审核 |

若需要主动核验某段原始论文而触及被遮蔽结论，走**显式、可审计的source verification例外**：记录请求来源、涉及组、实际解除的限制、时点和理由，并将该episode标记为 `exposure_override=true`；它不能再被当作未经揭示的纯masked实验样本。

禁止简单在Prompt里声明“忘记某个Alpha”作为遮蔽实现；完整遮蔽属于程序数据访问控制。

## 5. 生命周期

1. 总编排固定 Knowledge 快照和分组索引版本，执行full/masked配置。
2. 生成期所有初始卡与后续查询由统一可见性视图过滤；查询日志留痕。
3. M3返回Alpha候选后，结束此 `exposure_view_id` 的研究可见性上下文。
4. **独立** M4/M5/M6 使用全量真实Knowledge处理正式候选与金融评价；不能把被遮蔽Alpha误当不存在。
5. 记录 `seed, mask_probability, mask_group_index_version, exposure_view_id, visible/hidden组ID(仅日志), override, query_log`；生成内容不含隐藏组信息。

## 6. 限制与测试

Masking只能减少**显式研究输入的锚定**，不能擦除模型预训练知识、已发布Daily定义对研究方向的暗示或其他公开领域知识。若当前没有可遮蔽结论，masked与full输入等价，必须记录 `masked_group_count=0`，不得宣称有遮蔽效果。

测试覆盖：同seed同快照结果一致；不同seed能够形成不同候选视图但无需强行保证每次不同；直接ID查、全文检索、关系展开、论文段落访问均不能静默漏出遮蔽结论；全库M5检索不受生成期遮蔽影响；被允许的核验例外必须留下override标记。
