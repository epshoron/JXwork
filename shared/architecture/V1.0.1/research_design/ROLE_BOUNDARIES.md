# 角色边界及主观相关性审查

**主观职责重叠不等于因子数值相关性**；不要把 Alpha 最大绝对相关性 <0.65 的硬阈值误用于角色描述。16 人两两共 120 对；下表是重点交叉对，不代表其余所有组合已经审核通过。

| 易混角色 | 主责区别 | 判别方法 |
|---|---|---|
| A01 / A04 | 单日净方向及幅度 vs 分钟变化发生顺序 | 打乱分钟顺序，方向汇总可不变但路径指标会变 |
| A02 / A03 | 波动规模 vs 标准化分布形状 | 同比例放大分钟收益，部分形状值不变而规模变 |
| A03 / A04 | 收益经验分布 vs 有序路径 | 重新排列收益不改变纯分布，可能改变回撤/峰谷顺序 |
| A04 / A05 | 相对变化顺序 vs 实际市场钟点 | 保留顺序改变发生时段，A05关注时钟位置 |
| A02 / A06 | 单尺度风险量级 vs 多尺度之间的结构差异 | A06应比较至少两个合法采样分辨率，而非仅改窗口 |
| B01 / B02 | 多日记忆 vs 分布/结构稳定性变化 | 普通滑动均值不自动属于结构断裂 |
| B01 / B03 | 单特征历史变化 vs 同股多特征关系 | B03至少两个含义不同的特征 |
| C01 / C02 | 当日截面相对位置 vs 同分钟路径共动 | 数值排名不能替代时间同步关系 |
| C01 / C04 | 普通横截面 vs 行业/组别层级结构 | C04必须依赖有实际含义的历史分类 |
| C02 / C03 | 同时共振 vs 非零分钟领先/滞后 | 没有时间滞后不属于 C03 |
| C02 / C05 | 无条件共动 vs 特殊条件/非线性联动 | 简单截断不构成独立金融问题 |
| C01 / D01 | 当日相对位置 vs 多日地位演化 | D01必须使用多个日期的横截面地位 |
| C02 / D02 | 当日共振 vs 共振关系本身跨日期变化 | D02关注关系随日期演变 |
| B02 / D02 | 个股统计稳定性 vs 股票间关系稳定性 | 删除其他股票后若仍可计算则偏向 B02 |
| D01 / D02 | 相对排名变化 vs 群体依赖变化 | 历史名次与关系强度不是同一研究对象 |

归属步骤：先判定单/多股票、单/多日期；然后选择使研究问题成立所必需的**主要信息依赖**；若依赖确实跨组，则一个主责 ID 加 secondary_domains，而不是新建一个笼统万能 Agent。记录相邻角色冲突、公式/依赖去重。A06 和 C05 是重点实验审查对象：若只重复 A02/C02，就应在后续策略版本中合并或调整。

最终候选必须按实际信号及已成功 Alpha 集合走统一 Statistical Evaluator，并非角色职责设计已经保证金融独立性。
