# 角色采样与实验优化（调度参数尚未拍板）

**当前采用16个专业角色**，不等于每轮必须调用16次、必须创建16个LLM实例，更不等于已证明优于P002原21角色。

推荐的后续实验流程（不是已拍板的固定调度）：

1. 先校验各角色必要数据与时间合法性，缺必要字段就记录BLOCKED，不假造成交量或未来收益。
2. 建立覆盖四个范围的最小测试，保持相同模型、样本、Knowledge成功者快照和总生成预算。
3. 用统一Evaluator记录每个角色的代码可运行率、统计冗余、合格Alpha数量、单位成本、跨领域覆盖及样本外指标。
4. 对比当前16角色、P002原21角色或后续合并方案；早期角色面对的成功胜者少，比较需控制先后顺序影响。
5. 再决定每轮角色数、按组预算、Prompt Guidance、遗传变异/交叉的触发策略；每次改动要记录strategy_version。

A/C偏向原始分钟信息，B/D可复用已发布Daily；角色数量不规定调用预算。**所有16个Research Agent只输出日频Alpha候选**，由独立技术/统计/金融关卡审核；Daily中间特征的构造、审核、发布是M1 Daily Curator的专属职责。
