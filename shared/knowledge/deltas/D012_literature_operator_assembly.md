# D012｜P007：LEGO 金融文献到可执行 Alpha 运算符的构造

**审批**：2026-10-21 研究者已认可 **P007 文献引导 LEGO 公式构造**为值得保留的特色机制；**不是判定学术首次发明“利用文献挖因子”**。

- **要解决的问题**：因子搜索需要经济研究方向，但只拿现成因子公式变异容易局限在旧结构附近。
- **输入**：金融论文**题名与摘要**中的经济线索 + 允许使用的 OHLCV 数据变量、表达式运算符及语法约束。
- **操作位置**：在**候选生成/Prompt 组装**环节，将文献想法与可执行因子 DSL/公式运算符结合，让 LLM **不依赖预给的种子因子公式**，直接提出可运行 Alpha 表达式。
- **输出/更新对象**：新的可执行候选公式及解释；**LEGO 本身是生成先验而非更新 LLM 参数的算法**，参数更新归 [D013](D013_tmb_rl_factor_policy.md)。
- **语义去重结果**：
  - [D002（P001）](D002_structured_alpha_prior.md) 同是领域先验，但**输入是现成 WQ101 公式模式，并将它检索给 Writer**；D012 以**金融文献的自然语言观点**为源，再与数据/算子结合生成新公式，先验内容和生成干预不同。
  - [D006（P002）](D006_domain_guidance.md) 用预设 21 个金融主题角色 + 五类指导 Prompt；D012 不靠多角色分工，而靠**外部金融论文文本与算子语法的落地桥接**。
  - [D009（P003）](D009_hypothesis_factor_alignment.md) 是**对已生成的假设—描述—公式进行一致性打分**；D012 是**生成之前的来源引导与构造**，控制环节不同。
  - **结论：独立新卡**，但学术 novelty 待更广前作核对。
- **作者实验**：公开的论文消融表转录支持金融文献文本优于非金融文本，但**原始 Table 2 仍待直接核对**；模型/数据/随机种子等混杂因素需慎重解释。
- **不单独创立的内容**：一般 Prompt 工程、公式解析、允许算子语法、普通 LLM 因子生成、论文阅读，均不是新的独占 Delta。
- **特化不足状态**：另一个“文献假设与公式可能不一致”此前提出但**未获本次审批**，不写成正式风险。
- **证据**：[AlphaRLM arXiv:2610.14959](https://arxiv.org/abs/2610.14959)（方法 §3.2）；[P007 档案](../../papers/P007/ARCHITECTURE.md)。
