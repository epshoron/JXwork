# D019｜P010：五维交易语义 Plan 的生成前搜索表示

**审批状态（2026-10-22）**：研究者认可 AlphaSchema 的**五维结构化金融语义搜索空间**及其**词表覆盖边界**，作为值得追踪的特化机制和待验证问题。**不是学术首次提出结构化假设或金融语义的结论**。

## 机制指纹

- **输入**：由金融知识、文献及研究目标抽象的语义词表；论文主 OHLCV/VWAP 实验为 **140 个语义记录**（Event 40、Context 40、Qualities 50、Direction 3、Output 7）。
- **操作环节**：将计划明确组织为 `(Event, Context, Qualities, Direction, Output)`。Event 是市场事件，Context 是背景/参照，Qualities 是零至三项过滤/确认条件，Direction 是收益方向解释，Output 是输出信号形式。**先在金融语义组合空间采样、去重、选择研究计划**，再由 LLM 把选中的 Plan 落地为公式/代码；计划本身不规定具体算子或数值参数。
- **输出与更新对象**：可枚举、组合、变异、记录来源的语义 Plan，以及与其关联的实际因子实现；外部 LightGBM 如何学习 Plan 得分单独见 [D020](D020_semantic_reward_surrogate_scheduler.md)。**不更新生成 LLM 参数**。

## 同义排除与现有 Delta 的实际区别

- [D002 / P001](D002_structured_alpha_prior.md)：参考 **WorldQuant 101 既有因子公式结构**引导写因子；P010 搜索的是**不含具体公式的五维金融语义计划**。
- [D006 / P002](D006_domain_guidance.md)：依靠 **21 个金融主题 Agent + 五类 Prompt 风格**生成；P010 有显式可组合/可检索的 Plan 对象，不是给 Agent 多加几种研究角色。
- [D012 / P007](D012_literature_operator_assembly.md)：将**金融文献摘要/标题**与 DSL 算子一起引导公式生成；P010 可以用文献构造词表，但搜索单元是**结构化五维 Plan**，没有把文献文本直接等同于计划。
- [D009 / P003](D009_hypothesis_factor_alignment.md)：生成后对假设—描述—公式做**一致性检查**；P010 在**生成之前**把可搜索候选定义成五维金融语义。二者有假设约束背景，但实际作用位置不同。
- 与 [D020](D020_semantic_reward_surrogate_scheduler.md) **分工去重**：本卡只定义「**搜索什么**」，不重复叙述「**怎样利用奖励调度搜索**」的代理学习机制。

**结论**：保留独立机制卡；项目内部有明确表示层差异，**学术首创性仍需更全面查新**。

## 对应特化不足①：当前搜索受已有词表覆盖限制（待验证）

- **具体原因**：一次在线发现循环只对已定义语义条目作组合/替换；若某个金融机制在 Event/Context 等词表中均没有表达载体，就不会作为独立语义部件由在线组合凭空出现。
- **边界**：原文 Appendix C **明确允许在两个发现周期之间离线扩展/修订词表**，包括添加此前未覆盖的新机制，所以不能写成整个系统永远不能产生新概念。
- **验证问题**：在等量代码实现/市场评价预算下比较固定词表、人工或离线扩词表，以及不同来源词表，测量**原词表之外的独立有效因子和新增预测信息**；不能仅用候选公式数或代码多样性替代。
- **证据**：原文 §2.2、§3.1、Appendix C；Appendix E 对 100 个高奖励完整计划逐一删除某维，完整计划平均 `|RankIC|=0.0185`，删除维度后约 `0.0131–0.0147`。它支持字段完整性的效果，**不直接证明词表之外是否有遗漏 Alpha**。
