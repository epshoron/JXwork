# D006｜金融专业领域 Agent + 多样化 Prompt 搜索

**审批状态（2026-10-21）**：研究者已明确认可这项 **P002 特化机制贡献**，同时认可“固定主题分工可能造成因子同质化”作为**待验证风险**。**不表示学术首次提出或风险已发生**。

## 机制与相对前作的区别

- **原文机制**：CogAlpha 在七组金融主题中配置 **21 个生成 Agent**；这些 Agent 通过不同研究主题/角色 Prompt 探索 OHLCV 因子，再以 **light / moderate / creative / divergent / concrete** 五类提示引导扩展探索方向。输出是可执行 Python 因子代码，而非 21 个分别训练的模型。
- **相对项目 P001**：P001 的 D002 用 WorldQuant 101 经典公式的**检索式结构先验**指导 Writer；CogAlpha 则用**金融领域任务分工和多样化 Prompt**限定/扩展搜索。二者都提供搜索先验，但表达载体和候选生成方式不同。
- **贡献边界**：该具体设计已获研究者认可，能作为 P002 值得追踪的特色；多 Agent 与 Prompt 工程本身有先例，**没有完成同领域的系统学术首创性核查**。
- **原文依据**：[CogAlpha §3.1 Seven-Level Agent Hierarchy、§3.2 Diversified Guidance](https://arxiv.org/html/2511.18850#S3)，[Appendix A](https://arxiv.org/html/2511.18850#A1)。

## 研究者已认可的特化风险（**非实证结论**）

**固定 21 个主题 + 多样化 Prompt 可能只制造表面差异，未必增加独立 Alpha。** 趋势、量价和融合类 Agent 可能写出不同代码却高度相关的信号；**更多候选 ≠ 更多互补预测信息**。该问题源于此文特定的专业化搜索设计，而不是“所有回测都有过拟合”之类通用评价。

**验证要点**：在相同 LLM 搜索预算下测量结构/信号相似度、实际去重后的有效因子数、边际组合预测价值及严格未参与搜索的评估效果。作者的逐步叠加消融报告了完整系统提升，但不能单独证明 21 个方向各自产生独立 Alpha。

**研究者审批范围**：认可上面的特色贡献与风险假设，**没有批准“动态调配 21 个 Agent 的预算”等改进方法作为我们的原创方案**。
