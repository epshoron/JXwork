# P001｜作者的核心贡献与客观评价

[一页架构图](README.md) · [论文原文入口](PAPER.md) · [确认的特化疑问](IDEAS.md)

## 这篇论文做了什么

**经典公式结构（101 Alpha KB） → Writer 生成 → Judge 内循环检查 → Backtest/Reviewer 外循环反馈 → 达标因子进入 Main KB，后续检索复用。**

它研究的是**自动生成和检验新因子**，不是 LLM 直接决定买卖股票。内外循环分别负责代码/逻辑质量和预测效果；Main KB 保存历史达标因子。

## 论文贡献：作者说了什么，我们怎么判断

**已讨论认可的核心贡献**：把 **WorldQuant 101 的经典因子公式结构作为检索先验**，引导 LLM 生成因子，再与反馈循环、经验知识库配合。作者 [论文摘要/Highlights](https://www.sciencedirect.com/science/article/pii/S2666827026001520) 把这一结构化先验列为 key contribution，并报告比无约束生成更好。

**客观原创边界**：这篇的**系统组合有特点**，但**多 Agent、内外双循环、知识反馈并非都由其首创**：[QuantAgent (2024)](https://arxiv.org/abs/2402.03755) 已使用相关机制。能较有把握说的是“本文重点使用了怎样的领域公式先验”，不能在未系统查新前说“首次发明结构化先验”。

## 经讨论认可的特化不足（尚非实证定论）

**先验可能把搜索局限在已知公式附近。** WorldQuant 101 给出了可复用的算子组合与数学结构，能提高生成方向性，却也可能让 AI 主要改动经典表达式而不是产生独立的新思路。如果系统在有限的结构附近反复生成、回测和挑选，就有**因子同质化、搜索空间收缩，以及样本内选择性过拟合**的风险。

**关键是双面效应**：先验既可能提高有效生成率，也可能压缩探索的多样性；这是针对 P001 独特模块的具体权衡，而不是泛泛说“回测会过拟合”。**目前尚未证明 P001 发生了这一问题，也未核查它是否已有充分的多样性约束与消融。**

## 作者结果（只留判断必需信息）

据 [作者公开材料](https://github.com/VMSSON345/Self-Improving-Alpha-Mining-for-Quantitative-Trading-via-Multi-Agent-Large-Language-Models-with-Know)，越南股票市场约 449 只符合筛选条件的股票；10 个 held-out 研究想法中 9 个达到作者 IC 阈值，报告平均 IC ≈ **0.048**、Sharpe ≈ **2.39**（**未扣交易成本**）。它们是作者实验结果，不是独立复现，也不能凭此证明“先验不导致同质化”。
