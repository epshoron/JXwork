# P007｜AlphaRLM：已确认的两项特色机制与评价边界

[核心架构图与回测](README.md) · [原始预印本与核验状态](PAPER.md) · [经研究者认可的特化研究疑问](IDEAS.md)

## 一句话看懂

**金融文献标题/摘要 → LEGO 联合行情变量及运算符构造 Alpha 公式 → 合法性和 TMB 分组收益差奖励 → DAPO 更新“因子生成 LLM”的参数 → 生成新因子并在下游模型中检验。**

这里被训练的是**因子公式生成策略本身**，而不是用 LLM 重新设计收益预测器。它和 P002 CogAlpha 固定 LLM、演化候选代码的机制层级不同。

## 研究者已认可的特色贡献①：文献引导的 LEGO 公式构造

**具体做法**：把金融文献的**题名和摘要**作为经济研究的提示来源，结合限定的行情变量与可执行算子，直接让 LLM 组合出公式型 Alpha；**不要求提供一个现成因子作为变异种子**。

**严格语义去重**：它与 [D002/P001](../../knowledge/deltas/D002_structured_alpha_prior.md) 同属“领域先验”，但 D002 直接检索**现成 WQ101 因子公式结构**；这里检索/输入的是**论文经济学文本**，在生成环节把自然语言想法映射到允许的计算变量和算子。不同于 [D006/P002](../../knowledge/deltas/D006_domain_guidance.md) 的**预设 21 种金融研究角色及五类提示改写**。可以记录为这个任务中的**具体文献—算子落地机制**；不能宣称首次使用文献或首次发明算子语法。

**效果证据**：论文报告同一框架下，替换金融文献为非金融文本会显著降低回测表现；这些消融数值目前取自公开论文表转录，**尚待直接核对原始 PDF**，不据此声称已独立复现。

**身份**：2026-10-21 用户认可的**特色贡献/研究归档判断**，不是学术新颖性最终认证。

## 研究者已认可的特色贡献②：单因子 TMB 奖励指导参数级 RL

**具体做法**：对每条生成的 Alpha 公式先检查可执行性/时间合法性，再按因子值把股票分组，计算各组下一期的平均收益；**TMB 取组均值的最大差（最高组减最低组）**，即使最优和最差组不在因子大小排序的两端也能得到奖励。将有效性与收益分组信息作为奖励，使用 **DAPO** 直接优化因子生成 LLM 的策略参数。

**严格语义去重**：不能把“首次 RL 训练因子 LLM”记为本文独占贡献——[P005 AlphaPilot](../P005/README.md) 已描述离线 GRPO 更新生成 LLM。与 P005 的实质差异是**反馈对象与训练粒度**：P005 给**多轮工具调用后整个因子池的结果**打轨迹奖励；P007 用**单条公式是否合法、分组收益有多大差距**训练生成策略；与 P002 的 D007（**因子 Python 代码种群进化，不修改基础模型参数**）也不同。

**边界**：DAPO、强化学习和分组回报评价都不是本论文首次发明；此处认可的是 **TMB + 公式有效性 + 参数优化的具体搭配**，并非证明优于所有 RL 因子挖掘方法。

## 唯一经研究者批准、审慎保留的特化不足（待验证）

**TMB 的极值选择，可能在有限历史样本上放大偶然的分组收益差。** 如果某因子本无稳定预测信息，几个分组也可能因噪声出现偶然的“最高/最低组”差异；训练若一味奖励这一最大差距，可能偏好历史偶然极端值。**这是风险推断，不是已经证明 AlphaRLM 奖励失真**。

作者实验显示 TMB 在回测年化超额收益上优于端点分组的线性奖励变体，说明该设计**也有实际有效的证据**；不能只因存在统计风险就否定机制。未来若深入核验，需研究分组数、样本长度、重复训练种子、极值选择的稳定性与严格未参与奖励拟合的时间外收益。

**审批准确含义**：研究者认为这项不足也有些牵强，**仅同意谨慎记录这一条待验证质疑**；另一条“文献假设与公式可能脱节”未获本轮批准，不写入正式特化缺点。**不需要创新与缺点一一配对**。
