# B｜AI 优化 AI（论文研究档案）

- [papers/INDEX.md](papers/INDEX.md)：T001–T006 等来源论文、已审机制与证据状态。
- [knowledge/DELTA_INDEX.md](knowledge/DELTA_INDEX.md)：TD 系列机制与论文对照。
- [synthesis/](synthesis/README.md)：B 方向的综合研究。

这里研究**外部 Agent 优化**（Prompt、工具、工作流、记忆与检索）和**模型参数训练**（SFT/RL 等）两类路线。上层 AI 可以根据下层执行 Agent 的真实任务反馈提出和验证改进；但本仓库**没有实现完整 Meta Loop，也没有批准自动修改公司 Agent 或训练权重**。

本目录所有结果都是论文研究与设计参考，不是云端 Agent 的任务或 API 调用许可。完整研究原始导读/协作规则可从 `assistant/research_guides/` 查看。
