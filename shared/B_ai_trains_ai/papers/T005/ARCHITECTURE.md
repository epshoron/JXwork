# T005｜Self-Rewarding Language Models：两项获批特色机制及对应边界

[架构图与原文实测](README.md) · [原论文核验](PAPER.md) · [两项配对研究问题](IDEAS.md)

> **审批**：2026-10-22 研究者明确批准 **2 项具体特色 + 一一对应的 2 项特化不足**；是项目级机制评价，不是“全球首次发明 DPO/LLM-as-a-Judge”或已独立复现。

## ① Actor/Judge 共享权重的自反馈偏好数据 → 迭代 DPO

**输入**：预训练 Llama 2 70B；人类排序/指令示例初始化后的当前模型 `M_t`；主实验中由**另外一台固定 Llama 2-Chat 70B**生成的新指令。

**操作**：同一 `M_t` 为每条指令采样多条回答，然后以 LLM-as-a-Judge 提示评价**它自己生成的回答**；取最高/最低分生成 chosen/rejected 偏好对，使用 **DPO** 更新这个模型的**权重**，形成 `M_t → M_{t+1}`；下一轮生成者和 Judge 都随同一个新模型一起变化。实验的模型序列为 `M_1→M_2→M_3`。

**重要边界**：新指令生成器、人工种子、外部验证程序并未消失；DPO 是已有偏好训练算法，**不等于 LoRA**。创新辨识点是**自产偏好反馈与生成者/评价者同模型共享并更新**的闭环，而非普通“有自评”。

**对应特化不足①（已批准）**：同源评价可能反复强化自身偏好——例如更喜欢冗长答案→选更长答案作 chosen→下一代生成更长答案。作者实测 AlpacaEval 平均回复长度 `1092→1552→2552`（`M_1/M_2/M_3`），§6 明言长度偏好与 reward hacking 需要研究。**增长的长度是观察事实；发生 reward hacking 是尚未证实的风险**。作者也提供人评与其他基准，不能据此断定质量没有提升。检验需长度控制、独立人评/正确性与不同评分器对照。

**原文**：[§2.2–2.4（算法）](https://arxiv.org/html/2401.10020)；[§3.2（长度/人评）与 §6（局限）](https://arxiv.org/html/2401.10020)。

## ② IFT+EFT 双任务初始化及 Judge 评价能力的跨任务间接提升

**输入/初始化**：**IFT**（高质量人工指令-回答）训练回答能力；**EFT**（从有人类偏好排序的数据生成并筛选 Judge 的评分解释/分数）让模型学会评价。两类数据共用一个基础 LLM，以 SFT 得到既能回答、也能 Judge 的 `M_1`。

**更新途径**：随后的 DPO 以**回答的 chosen/rejected 偏好对**优化共享参数，**没有每一轮再增加新的 EFT 监督**。论文观察到 Judge 在独立保留的人类偏好集上的 **Pairwise Accuracy `78.7%→80.4%→81.7%`**。作者提出的解释是：改进一般指令遵循可迁移到 Judge 任务；这是**有实验现象支撑的假设解释**，还不是独立识别的因果机制。

**对应特化不足②（已批准）**：Judge 的下一轮改进来自间接共享参数迁移，并无每轮的直接评价质量优化保证。Table 4 的 **5-best 44.3%→43.2%（`M_2→M_3`）下降**、**Exact Match 14.3%→14.3% 不变**，说明不同 Judge 指标并非同步持续提高。作者 §6 只验证三个模型阶段、一个主要设置，未证明长期迭代会持续改善。**不能据此断言 Judge 整体退化**：Pairwise、Spearman 和 Kendall 同期仍有改善。可追加 Judge 独立验证、延长轮次、跨模型复验和对 Judge 专项反馈的消融。

**原文**：[§2.1 IFT/EFT](https://arxiv.org/html/2401.10020)；[§3.2 Table 4 / Appendix A.3](https://arxiv.org/html/2401.10020)；[§6](https://arxiv.org/html/2401.10020)。

## 严格语义去重（与最新 A/B 知识库）

- **T001/TD001–TD002** 搜索的是自然语言 Prompt P/M 或 successful trace→few-shot/P，**固定基础 LLM 权重**；本篇是**DPO 真正改变模型参数**。相同的词“自我进化/反馈”不构成重复。
- **T002/TD003–TD005** 的 GEPA 是运行/诊断轨迹导向的**模块 Prompt 改写、Pareto 父代调度及模块合并**，仍未修改基础权重；不重复。
- **方向 A D013/D015/D016** 也使用参数训练，但对象分别为**因子公式市场 TMB**、**种子因子多目标进化轨迹**、**最终因子池 IC/RankIC**；没有 T005 这种**通用回答模型兼任 Judge 产出自有偏好对、评价能力可跨任务改变**的机制。无需把 DPO 或“RL 微调模型”再单独建卡。
- **① 与 ② 也不重复**：① 指**每轮生成答案→自评分→构建偏好对→更新参数的反馈链**；② 指**IFT/EFT 初始多任务能力 + 后续回答训练向 Judge 评价任务的参数迁移**。两者输入、起效位置和验证证据不同。对应不足①是**自评偏好闭环强化**；不足②是**Judge 跨任务迁移的可持续性/指标不一致**，不是把同一泛化风险拆成两条。

**证据身份**：正式发表 ICML 2024，作者 Table 4/§3/§6 的数值和自述局限有原文支持；自我强化偏好可能造成 reward hacking 的“是否实际发生”仍待独立实验；尚未复现、未认证学术世界首创。仍属方向 B 阶段一单篇审批。
