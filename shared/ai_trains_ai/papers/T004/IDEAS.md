# T004｜ADAS 已批准的两项特色对应特化问题（2026-10-22）

> 研究者批准 **2 组机制 + 各自 1 个问题**，均有可追溯设计/证据；「需要验证」不等于「已实证出现故障」。参见 [ARCHITECTURE](ARCHITECTURE.md) 与 [原文](PAPER.md)。

## ① TD010 ↔ 开放式 Agent 结构搜索的性能—计算成本归因

- **对应特色**：[TD010](../../knowledge/deltas/TD010_executable_agent_program_search.md)：上层 Meta Agent 生成整个 Agent 可执行 `forward(taskInfo)`，可以改变模块数量、调用次数、反馈循环与集成逻辑。
- **原因与原文证据**：主研究按任务 F1/准确率评估结构；复杂设计可能通过更多推理调用得到更高分数，作者 §6 将多目标成本、时间等作为未来方向，Appendix K 报告搜索 API 成本。
- **具体待核问题**：在**固定底层模型、任务、最大轮数、调用与 Token 预算**后，搜索得到的 Agent 结构相对同预算基线还能改善多少？给出准确率—成本—延迟权衡及样本外表现。
- **身份**：作者明确的评价范围局限 + 研究者提出的**未隔离的计算归因问题**；不等于性能提升已被证实来自堆调用。

## ② TD011 ↔ 初始人类种子偏置与动态档案价值不能混为一谈

- **对应特色**：[TD011](../../knowledge/deltas/TD011_agent_design_archive_stepping_stones.md)：历轮 Agent 设计理念、完整代码、实测成绩持续入 Archive，下一轮供 Meta Agent 组合与借鉴。
- **原文直接观察**：Appendix J Table 6：在 MGSM 上，带人工种子搜索 53.4，空档案初始化 67.5；另外三个任务总体带种子效果更好，不能称所有历史经验都有害。
- **证据与归因边界**：这个实验改变**启动时是否给人类设计种子**，两组均允许后续保存、读取新 Agent，因而**没有单独关闭持续 Archive**。作者对预置模式可能约束探索的解释也未通过单独实验证实。
- **具体待核问题**：固定总体搜索与上下文预算，正交消融初始有/无种子、各轮有/无历史读取；再比较只留最高分、保留失败案例、按结构多样性保留不同方案的效果，量化可迁移改进和设计多样性。

**不用通用“记忆过拟合”“成本高”制造第三、四条缺点**，也不把代码报错修复或尚未实现的 Meta Agent 自我优化误记为独立创新。原文 [ICLR 2025 §2–6、Figure 3、Appendix J/K](https://proceedings.iclr.cc/paper_files/paper/2025/file/36b7acf6f6010652b3f2a433774a66fe-Paper-Conference.pdf)。
