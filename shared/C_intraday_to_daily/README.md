# C｜分钟级量价数据到 Daily 特征（研究来源）

这是用于金融现象、分钟级统计量与日频中间特征构造的**论文/券商研报知识源**，不预设具体交易策略。

- [papers/INDEX.md](papers/INDEX.md)：C 学术论文原始档案与证据状态。
- [reports/INDEX.md](reports/INDEX.md)：CR 券商研报原始档案与证据状态。
- 编号 `N` 表示预计原始分钟字段**不足以原样复现**主要方法（不是论文无效），`A` 表示研究重点偏模型架构；最终以来源详情为准。
- 目前关于分钟数据可能具有 O/C/V/VWAP、H/L 不确定、缺逐笔/委托的描述，**仅是此前预计字段**，必须在公司环境中核实后才能计算。

**研究思路**：分钟数据 → 合法的计算及聚合 → 每股每日 Daily 特征 → 时间与依赖验证。原文计算可行性与真实市场效果必须分别验证。V1.0.1 中 Daily 库的相关性硬门槛为 **< 0.6**，具体相关性度量/比较范围仍待确认；**不可**用该 0.6 自动替代 Alpha 统计检查的尚未确认阈值。
