# AI 因子挖掘机制地图｜界面基准规范

**状态：用户认可的 v0.3 主界面升级为 Atlas v1.0 基准**（2026-10-23）。

## 1. 不随意改动的主界面

- 保留原有深海军蓝页头、浅灰背景、白色卡片、左 / 中 / 右三栏研究地图布局及响应式样式。
- 中间统一骨架的 **SVG 节点和箭头结构视为固定基准**：①任务/数据、②构思、③生成、④质量检查、⑤实验评价、⑥筛选留存，以及下游、反馈/搜索控制、LLM 参数更新、研究对象扩展。不得为了单篇论文私自添加、删除、重排节点。
- 左侧最多同时选择 **3 篇**论文；勾选后的节点标记同步出现在中间流程图，点击标记定位右侧简述。
- 右侧每篇只展示：论文名称、一句话定位、各落点的**短句机制解释**以及通向独立解析页的真实链接。不恢复冗长逐步遍历、重复总结或无必要的研究笔记段落。
- 对外文案使用 **“关键机制”（●）**、**“实现差异”（○）**、**“机制落点”**等清晰术语，不使用内部讨论的比喻称呼。

## 2. 论文标记的判定标准

- **● 关键机制**：输入、控制环节、更新对象或结构关系有明确、可描述的具体方法变化。并不等于经系统查新证明的学术首创。
- **○ 实现差异**：具体实现、数据源、任务分工等不同，但无需作为独立方法突破强调。
- **不标记**：骨架正常运行所需却没有具体辨识度的常规操作。
- 同一机制可在多个节点出现，**标记数量不等于独立创新数量**。每处标记须说明本节点实际做了什么。
- 必须区分候选公式变化、外部知识/搜索状态变化、外部代理模型参数训练、生成 LLM 权重训练。

## 3. 独立论文详情页

- 从 `index.html` 通过相对链接进入 `papers/P001.html`～`P010.html`；每篇都能返回首页并切换相邻论文。
- 保持主页配色、字体层级、留白、卡片语汇；内容依次为：**一句话定位 → 自绘流程图 → 具体例子 → 关键机制 → 更新对象与差异 → 证据边界 → 来源**。
- 用图和短段落讲懂，不堆砌大量公式、逐条参数和全文摘要；难术语第一次出现做一句通俗解释。
- 每页放可点击的原论文入口、JXwork 对应的 P00X 研究目录；说明作者报告与独立核验的边界。
- 资料范围：只使用方向 A 已核实并讨论认可的 P001–P010 研究材料；不会在展示页中自动建立新的学术创新或缺点记录。

## 4. 发布与安全

- **离线优先**：不引入 CDN 字体、在线 JS、Mermaid 云渲染或远端接口；从 ZIP 解压后双击 `index.html` 即可运行。本地站点的纸张/流程图/内部导航不依赖联网，外部原论文链接需要联网。
- 研究仓库内集中放置 `visualization/alpha-factor-atlas/`，与正式的 `papers/`、`knowledge/` 和方向 B 档案隔离。
- 不上传公司数据、API Key、内部代码或未经允许再分发的论文 PDF。
- 任何后续 UI 改版先保持 v0.3 主骨架不变，并在说明中列出实际变动范围。
