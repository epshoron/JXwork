如何使用

  1. 先将 ZIP 完整解压，不要在压缩包预览界面直接双击 Excel。
  2. 打开 JXwork_P001-P010_Engineering_QA.xlsx，每个工作表对应一篇论文，格式与列宽、行高一致。
  3. 第 D 列“补充资料”可点击，打开同级 resources/ 文件夹里的 HTML。网页是本地文件，可离线查看已有研究说明和流程图。
  4. 四份补充研究说明同时提供 Markdown 原稿；其他原始外部论文/作者源码有本地说明入口，实际原始网站需联网。
  5. Excel/WPS/操作系统可能对本地文件超链接弹出安全提示；这是软件防护措施，允许打开后可访问对应文件。不同平台安全策略无法通过 ZIP 文件强制覆盖。
