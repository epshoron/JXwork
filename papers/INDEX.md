## 轻量认领协议

1. 开始处理任何原始论文前，研究 Agent **实时刷新本索引**，按 DOI、arXiv ID 和原始标题查重；已有认领原则上另选，避免重复研究。
2. 确定要研究时立即登记：统一编号 `P001、P002、P003…`、真实题名、权威公开原文链接和最小状态。「认领」不代表已读过，更不等于完整理解。
3. **不以聊天窗口编号命名论文或认领人**。通过统一的「已认领」「阶段一研读中」「阶段一对话研读已完成」等状态就能协同；状态更新不等同论文内容归档。
4. 不在索引添加机制分类、实验结果、逐篇笔记或创新/缺点判断。**阶段一完整阅读理解 → 阶段二比较整合创新/不足 → 阶段三有机结合提出研究想法**；参见 `../RESEARCH_PLAN.md`。
5. 阅读正文由研究 Agent 优先自行访问官方 HTML、公开 PDF、出版方或作者版本；**无需等待研究者逐篇下载 PDF**。确实访问不了时保留可靠原文链接，在对话中说明缺失内容。除获得公开再分发许可，不上传 PDF 到 Public 仓库。
6. 只在认领/必要状态变化时更新本索引；写前获取最新 SHA，遇冲突则重新读取并合并。跨 Agent 协作以此文件为准，不查彼此聊天。
7. 论文实质讨论在 LLM 对话内进行；经用户确认后才将压缩、可核验的阶段性或最终成果归档到 `../synthesis/`。
