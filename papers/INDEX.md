## 必须同步更新：每个 Agent 的收尾义务（硬门槛）

**每个研究 Agent 必须自己负责“论文 Markdown ↔ 本 INDEX ↔ 相关 Delta 索引”的一致性；不能指望别的 Agent 或后续会话补齐。** 新认领、骨架落档、已审批内容落档、重要证据状态改变、放弃/撤回时，**在同一工作回合更新本行的最小状态**，只写实际完成的内容、不记录过程流水账；仅对话探讨、无真实状态改变则不必刷屏更新。

- 已更动 `papers/P00X/*.md` → **必须核查并按实际状态同步 `papers/INDEX.md`**；论文新建先登记唯一编号避免撞号。不得在索引混入未经批准的创新或详细缺点。
- 已更动、删除或新增 `knowledge/deltas/D00X_*.md` → **必须同步 `knowledge/DELTA_INDEX.md`、相关论文的已审批机制引用**；不得把候选/未经审批的差异标记为已确认。
- 协作流程、权限、审批或写作规则改变 → **必须同步 `AGENTS.md` 和 `RESEARCH_WRITING_STANDARD.md`**，并检查 `README.md`、`RESEARCH_PLAN.md`、相关目录指引是否有冲突旧说法。普通论文状态更新不需要机械修改 AGENTS，但必须按最新版执行。
- **提交结束前强制逐项复核**：现有 Markdown 文件是否存在？链接能否跳转？索引是否漏行、表格是否因空行被截断？状态与档案中的「已审/未审、已读/待核」是否一致？其他 Agent 的新记录是否保留？凡未同步完成的工作不得宣称“已归档完成”。
- 共享文件**每次写前读取最新版本和 SHA**，发生冲突必须重新读取、合并和重做一致性检查。非论文学术来源仍须**先经研究者批准**才能登记。

## 轻量认领协议

1. 开始处理原始论文前，研究 Agent **实时刷新本索引**，按 DOI、arXiv ID 和原始标题查重；已有认领原则上另选，避免重复研究。**非论文来源须先获研究者明确批准，未经许可不登记或建档。**
2. 确定要研究论文时立即登记：统一编号 `P00X`、真实题名、权威公开原文链接和最小状态。「认领」不代表已读过，更不等于完整理解。
3. **不以聊天窗口编号命名论文或认领人**。通过统一的「已认领」「阶段一研读中」「阶段一对话研读已完成」等状态就能协同；状态更新不等同论文内容归档。
4. 不在索引添加机制分类、实验结果或创新/缺点判断；**用户确认的单篇成果**存入对应 `P00X/`，跨论文机制差异存入 `../knowledge/`，整体研究总结放 `../synthesis/`。**先画骨架；创新点、特化缺点和 Delta 必须讨论获批再落库；项目三阶段顺序仍有效**；参见 `../RESEARCH_PLAN.md`。
5. 阅读正文由研究 Agent 优先自行访问官方 HTML、公开 PDF、出版方或作者版本；**无需等待研究者逐篇下载 PDF**。确实访问不了时保留可靠原文链接，在对话中说明缺失内容。除获得公开再分发许可，不上传 PDF 到 Public 仓库。
6. **认领、骨架/审批归档、撤回及其他真实状态变化时必须立即同步本索引**；不改变状态的闲聊不更新。共享文件写前获取最新 SHA，遇冲突重新读取并合并。跨 Agent 以仓库最新文件为准，不查彼此聊天。
7. 论文实质讨论在 LLM 对话内进行；研究 Agent 核实**论文原文**后可**直接归档 `P00X/` 的来源和架构，无须审图，但仍须向研究者讲解**；**其他来源即使只写来源/骨架也必须先获得研究者批准**。贡献评价、特化不足、研究者想法和创新 Delta 须另外逐项批准并严格语义去重才写入。跨论文通用机制及其增量进入 `../knowledge/`；成熟的项目级综合成果才进入 `../synthesis/`。
