## 1. 论文在做什么？

不是让 LLM 直接下单，也不是只从既有因子库里选因子。它让 Agent **自动产生新的因子公式/代码**，进行代码质量审核和历史预测能力检验，使用反馈再修改，并积累符合条件的 Alpha。

## 2. 方法骨架

| 模块 | 作用 | 记忆点 |
|---|---|---|
| 101 Alpha KB | 从 WorldQuant 101 Formulaic Alphas 检索公式结构与运算模式 | **经典知识先验** |
| Writer → Judge | 先生成，再查代码、金融逻辑、稳定性和前视风险；失败继续修正 | **内循环：能不能正确表达、执行** |
| Backtest → Reviewer → Writer | 历史数据评价、反馈，再生成下一版 | **外循环：预测效果怎么样** |
| KB Updater → Main KB | 把满足阈值的最佳因子保存，并在后续任务中检索使用 | **跨轮次成功经验记忆** |

实际是否每条规则都完全发挥作用，要用正文及代码检验。图为研究者整理，并非论文原图。

## 4. 成果与证据边界

作者公开项目所报告：越南股票市场筛出 **449** 只样本股票；最终保留测试集上 **10** 个交易想法中 **9** 个产生 IC ≥ 0.01 的因子；平均 IC **0.048**、ICIR **0.4711**、Sharpe **2.39**；平均每想法约 **1.5 分钟**。作者描述使用按时间顺序的 train/validation/test 分割，最后测试时冻结 Main KB。

**重要口径**：期刊 Highlights 明确 2.39 是 **gross-of-cost Sharpe（未扣交易成本）**；不能说实盘净 Sharpe=2.39。这些是**作者的实验报告**，没有独立复现。正式摘要指出 WQ101 先验相对无约束生成更好，但本仓库尚未逐表核实差异大小及误差范围。

## 5. 客观评价：成功点与不足/尚未证明之处

**评价中的肯定**：

- 系统控制流清楚：把生成、代码质量检查和客观评测分离；既能修正写错的代码，又能针对弱预测性能改写因子。
- 使用经典公式先验使生成更有金融结构约束；作者报告它优于无约束生成，并给出量化市场样本外实验。
- 最终测试时冻结知识库，体现作者意识到知识检索与回测之间的隔离需要。

**需要谨慎看待的边界**（不把“未看到证据”偷换成“作者一定没做”）：

1. **交易可实现性**：已知 Sharpe 是未扣费指标；扣交易成本、冲击、换手、流动性后能否维持，**尚未由当前可核资料证明**。
2. **外部适用性**：当前公开实验证据聚焦越南一个市场、少量 held-out 想法；跨市场、跨周期稳健性尚不充分。
3. **新颖性和多样性**：依靠经典公式与成功案例可能加强同质化；是否做过 AST/语义/因子相关性去重，**待全文/代码核验**，不可直接断言没有。
4. **重复搜索后的统计选择偏差**：多次试验容易出现偶然高 IC。冻结测试期是积极设计，但独立种子、试验预算、统计校正等需要进一步查表。
5. **“自我改进”的具体层级**：当前可确认是**候选代码 + 检索知识积累**；不能宣称模型参数自动训练、跨任务自主优化搜索器或严格 RSI。
6. **学术 novelty 的归属**：两个循环和知识反馈存在 2024 年前作；本篇作者提出的具体组合是否具有排他性首创，需要更多系统对比。

当前既不宜说「没有创新」，也不能说「全套机制完全原创」；更可靠的评价是**领域先验驱动的因子生成组合有明确贡献主张和初步验证，但可交易稳健性、机制增益幅度及原创边界还需要更细的原文与前作核对**。
