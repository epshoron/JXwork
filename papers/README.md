# papers / 原始论文

此目录用于组织 **LLM/Agent 因子发现及相关自我改进研究的原始论文来源**。

- 首先在 [INDEX.md](INDEX.md) 登记论文身份、原文链接、版本、状态和对应阅读笔记。
- 仅在许可允许公开再分发时，才把原始 PDF 保存到这个**公开**仓库。
- 不能公开存档的 PDF：只保留官方链接/DOI/arXiv、许可信息；文件应放在依法合规且授权的个人本地存储，不能绕过限制上传。
- 文件名建议：`YYYY_FirstAuthor_ShortTitle.pdf`，避免重复版本。
- 优先引用原论文，不把二手博客里的公式或转述当成原始证据。
