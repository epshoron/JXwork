## 本轮直接核实的论文位置

- **§3.1–3.7**：SJS 将因子 `f` 与内部指标 `g` 视为不同搜索对象；独立生产角色、限定跨轮摘要、记录来源的角色权限、技能库、晋级规则、Agora 实现。
- **§4.1–4.4**：训练 **2014-10—2019-12**、验证 **2020-01—2025-12**、最终留出 **2026-01—2026-05**；AlphaGen 语言和 PPO 组件、五类角色/九个 LLM 实例；验证段只向指标研究侧传输有限分类信息。
- **§4.3 Promotion Rules**：trial 指标的分数与 **训练段** Sharpe 形成观测对，`n>=3` 且绝对相关 `>0.3` 时自动晋级；也有 Agent 申请、评价组审核的路径。相关下降可触发降级。原文 §5.7 报告 80 次新指标提案、2 项晋级；其他技能库没有观察到同样的实质演化。
- **§5 / §6 / Appendix A**：作者的实验结果、消融与明确的限制；封存留出时段用于最终评价，**不是整个验证区间都未在环路里被间接查看**。作者只给单种子完整系统结果，报告 Sharpe 主要来自空头。论文也明确说明指标升级使用训练 Sharpe 自身存在循环依据，而非独立外部效用。

## 核验边界及需要进一步确认的细节

1. **尚未独立运行源码**：论文表示开放实现，但本轮未确认官方源码仓库的可访问位置，不得描述为已经跑通或代码复现。
2. **统计主张有限**：作者报告封存组合多空 Sharpe +1.87，但没有完整多种子 Agora 重复试验；与若干基线的 HAC 差异并不显著。收益和新颖性不得直接作为我们确认的创新结论。
3. **「8 个技能库」的表述需谨慎**：§4.3 行文使用 eight typed skill libraries，§5.7 Table 7 枚举时还单列宏观市场状态库，具体口径须以系统注册配置核对，因此架构图不预设未经核查的唯一数量。
4. **材料边界**：尚未核验完整图形及附录所有脚本。此档只归档已经从可读原文核实的信息；独立创新判断、特化不足、知识 Delta **待研究者在对话中逐项审批并严格语义去重后再归档**。
