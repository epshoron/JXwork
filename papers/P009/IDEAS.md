# P009｜两项研究者已批准的特化不足（未必构成实证故障）

**审批：2026-10-22｜两项**。这是对论文特定设计与实验的**可检验批评**，不是断言系统确已失效，也不代表已启动阶段三原创方案。

[已批准两项特色机制](ARCHITECTURE.md) · [客观骨架](README.md) · [原始论文](https://arxiv.org/html/2606.29194)

## 不足①｜评价指标晋级依据的自我强化

**独特设计 → 失效路径 → 后果 → 证据**

- **设计**：新评分指标 `g` 的自动晋级依赖其分数与**训练集 Sharpe** 的相关（至少 3 个观测，绝对相关 `>0.3`；已接受指标跌至 `<0.05` 才自动降级），而因子研究线也在优化训练表现。还允许 Agent 申请、评价者审核晋级。
- **可能的失效链**：如果两条搜索线围绕同一个训练期目标持续共适应，新增 `g` 可能只更有效地挑出**适合本次历史样本**的因子，而非真正提高未来收益识别能力。由指标研究 Agent 与因子 Agent 分离**不能自动消除**共同目标带来的统计循环。
- **具有原文依据的预警**：`monotonicity_score_v1` 在 R21 经 Agent 申请/评审晋级，训练 Sharpe 的相关性从当时约 **+0.47** 到 R100 降为 **+0.158**，虽低于 `0.3` 晋级线，但未跌破 `0.05` 降级线，故仍保持 accepted；**这仅展示晋级依据随样本/因子池变化的稳定性问题，不证明 holdout 绩效必然下降**。
- **核验方向**：在等预算/同类候选下，对照固定指标、动态指标、与独立时间段/不共用训练 Sharpe 的指标晋级依据，检查晋级指标跨时间的一致性、选中因子的真正封存表现及其方差。

**证据身份**：作者 §3.3、§6 **明确承认闭环指标晋级存在内部目标循环**；上面“可能双方共同迎合训练分数”是我们的**特化风险推论**，没有被实验实证为失败。它不是 D010 的**相对 Alpha Zoo 排名 + MCTS 历史最大回传**风险，也不是 D013 的**单公式分位极端收益取最大差**风险。

## 不足②｜关键对照不充分，机制贡献尚不能独立归因

**独特设计 → 证据缺口 → 影响 → 需要的对照**

- **设计**：论文主张联合搜索 `f/g` 时的 SJS **角色拆分（F1）+ 权限信息流（F2/F3）+ 可进化技能库/晋级（F4/F5）**能避免评分器与生成器互相迎合。
- **关键缺口 1（作者明确自认）**：没有实验让**同一个 LLM 同时提出 Alpha 与评价指标，同时保留指标可进化**。因此不能检验 F1 的独立必要性，不能用「单 LLM 只做迭代因子」对照替代这项测试。
- **关键缺口 2（预算与混杂）**：完整 Agora **100 轮、带 PPO 中继**，冻结技能库 B6 主要是 **5 轮且关闭 PPO**；论文虽补了 20 轮的「预装两指标、冻结库」对照，但并非完整等预算/等组件消融。报告 Sharpe 差异可能混合指标库更新、模型/搜索中继、候选数量与轮数的效应。
- **影响**：目前可证明**这一整套系统在作者给定历史模拟的点估计上表现更好**，但不能证明“双 Agent 隔离”或“自进化指标”**各自独立导致收益改善**；这与“算法没有效果”是两种不同判断。
- **核验方向**：同预算单 Agent 联合进化 vs 分角色联合进化；100 轮多种子完整 Agora vs 100 轮冻结库（保留/关闭 PPO 分别控制）；与等工具/候选/时间开销的消融比较。

**证据身份**：作者 §5.8、§6、Appendix A.9 对 **缺少单 Agent 联合进化对照、冻结库轮数差异、PPO 组件混杂和单种子**均有明确说明。与 [P008 奖励模块逐项消融](../P008/IDEAS.md) 在上位概念上同属“归因不足”，但**缺的实验及其因果对象具体不同**：P008 要确认五类奖励项及其组合形式；P009 要确认**联合进化下 F1 隔离是否必要，以及 F4/F5 在等轮数/等 PPO 设置下是否贡献独立增益**。不单列新的“消融不足” Delta。

## 只保留两条，不重复发明不足

- **不足①**是**真实搜索机制的内部目标共适应风险**；可以在不谈对照缺失时独立成立。
- **不足②**是**现有实验不能隔离拓扑分工与指标进化的因果贡献**；不等于机制已发生共适应失败。
- 作者其他报告边界（单种子、91 日严格留出、收益偏空头、其他 7 库未真正进化）仅保留在 [PAPER.md](PAPER.md) 和架构中作为解释范围，**不按同义词再拆新风险卡**。
