# P008｜AlphaAgentEvo：研究者认可的两项工程与训练机制贡献

[核心架构图](README.md) · [正式来源与核验边界](PAPER.md) · [D014：种子因子连续进化](../../knowledge/deltas/D014_seed_conditioned_evolution.md) · [D015：多目标分层奖励](../../knowledge/deltas/D015_hierarchical_evolution_reward.md)

## 一句话结论

**把“改进某个给定 Alpha”组织成可学习的多轮工具交互轨迹，再以同时约束保真、探索和持续改善的五类奖励训练进化策略。** 研究者认可这是具体而有价值的**工程/训练设计增量**；不等于首创多轮 Agent、GRPO 或遗传进化。

## 已获研究者认可①：围绕种子 Alpha 的连续进化式 Agent 工作流

**输入与目标**：给定已有种子因子（Seed Alpha），不是从头构造每日因子池，而是试图产出比种子更好的后代系列，保留可追溯的研究方向。

**工程控制环节**：同一个 RL 训练的 Agent 在多轮中思考/修改候选 → 调用市场因子评价工具 → 获取测量反馈 → 参考前几轮的候选与失败/成功记录继续提出下一代。**被学习的是因子进化的行动策略及跨轮改进方式**，不是仅将最终高分因子留在外部候选库。

**语义去重**：与 [P005 AlphaPilot](../P005/README.md) 共用**多轮工具使用＋RL 参数更新**基本架构，不能拿这一共性当新发明；P005 管理的是**当前股票环境下整个因子池的增删与边际贡献**，P008 专门让策略以**一个种子为锚点持续改造其后代**。与 [D007 CogAlpha](../../knowledge/deltas/D007_code_evolution.md) 的**固定 LLM 权重下代码种群变异/交叉**相比，P008 还通过多轮轨迹奖励训练进化策略参数。**区别在优化对象和任务组织，不在于是否有反馈。**

**审批边界**：这是被认可的具体工程化贡献，并不证明“从种子连续改造”在全球学界首次出现。

## 已获研究者认可②：五目标分层奖励共同塑造进化行为

| 奖励模块 | 要奖励/约束的行为 |
|---|---|
| Tool Call | 工具调用有效性及调用效率；减少低价值暴力尝试 |
| Consistency | 保留种子因子相关的研究方向/结构联系 |
| Exploration | 避免重复前面几轮的候选，扩大尝试范围 |
| Performance | 提升候选相对于种子的预测/回测表现 |
| Streak | 关注一条进化轨迹中的**连续改善**，而不只奖励一次性高分 |

**用户认可的设计要点**：目标存在**有意义的张力**——一味保留种子会妨碍探索，一味探索会丧失原方向，一味求最高分也可能忽略稳定的改善过程。这是多目标奖励的权衡对象，而**不是论文的特化缺陷**。奖励在论文中有截断、组合/比例关系，**不是把五个术语平铺相加**。

**实验支持及范围**：作者报告在 AlphaEvo500 上，完整模型 Pass@3 为 **0.65**；去除 Exploration 为 **0.54**，去除 Consistency 为 **0.51**。这支持二者在该实验中的**互补作用**，却不能据此声称另外三项的独立效果都已拆分证明，也不能把 Pass@3 直接写成组合年化收益。

**语义去重**：[P005](../P005/README.md) 对整条工具轨迹最终形成的**因子池 IC/RankIC**作奖励；[D013 / P007](../../knowledge/deltas/D013_tmb_rl_factor_policy.md) 针对**单个生成公式的有效性及分组收益差**作奖励；[D010 / P004](../../knowledge/deltas/D010_mcts_multidimensional_search.md) 将指标回传树节点价值。P008 的重点是**种子一致性＋探索差异＋相对种子改进＋连续进步＋工具约束**的训练信号及其联合组织，评价位置和更新对象不同。

**审批边界**：研究者认可五类奖励的**组合设计与具体权衡**是值得记录的特色创新；并未认证五个基础奖励分别为学术首创。
