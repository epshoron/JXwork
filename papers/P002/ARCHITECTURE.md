# P002｜CogAlpha：架构细化、作者贡献与客观评价

> 单篇论文的结构化研究成果；[原文来源](PAPER.md)｜[一眼看懂的 Mermaid 总图](README.md)｜[我们的研究想法](IDEAS.md)。不是逐篇读书过程流水账。

## 1. 真正在研究什么？

CogAlpha 从 OHLCV 价格成交数据中**创造新的可运行 Python 因子代码**，借助 LLM 的金融语言/编程能力扩展搜索空间，以审查、量化评估、种群演化和反馈筛选较有效的因子。下游 LightGBM/Ridge 预测和 Qlib 回测用于检验其作用，**不是 LLM 直接训练自己或直接做交易决策**。

## 2. 21 个“专业 Agent”如何实现？

**不是 21 个不同参数的模型**：作者默认以 `gpt-oss-120b` 配合不同角色 Prompt，让每位 Agent 负责一个研究任务，并**独立**产出候选；七个“层级”更适合作为从宏观到微观的**主题组织**，不是七层串行神经网络。

| 主题层级（共 21 个 Agent） | 数量 | 研究任务 |
|---|---:|---|
| I 市场结构与周期 | 2 | 市场周期、波动状态 |
| II 极端风险与脆弱性 | 2 | 尾部风险、崩盘先兆 |
| III 量价动态 | 4 | 流动性、买卖力量代理、量价一致性、成交结构 |
| IV 价格与波动行为 | 5 | 趋势、反转、区间波动、滞后反应、波动非对称 |
| V 多尺度复杂性 | 2 | 回撤、分形/多尺度特征 |
| VI 稳定性与状态门控 | 2 | 信号稳定性、在特定行情才启用 |
| VII 几何与融合 | 4 | K 线结构、非线性/复合因子、羊群行为 |
| **总计** | **21** | **基于同一 OHLCV，分不同金融假设方向搜索** |

每个方向再使用 **light / moderate / creative / divergent / concrete** 五种 Prompt 改写（Diversified Guidance），引导更多不同候选。这些 Agent **不以相互辩论为主要动作**；它们的代码汇合到统一的质检、评分及进化流程。参见[§3.1–3.2](https://arxiv.org/html/2511.18850#S3)。

## 3. 搜索控制谁说了算？

| 阶段 | 如何实现 | 谁改变了什么 |
|---|---|---|
| **候选提出** | 主题 Agent + 多样化 Prompt，LLM 编写带解释的 Python 代码 | **LLM** 提出候选因子 |
| **质量检查** | Code Quality、Code Repair、Judge、Logic Improvement 等角色；数值稳定性、时间泄漏测试 | **审核/执行器** 修复或拒绝不可用候选 |
| **效果评分** | IC、ICIR、RankIC、RankICIR、MI，多项门槛筛选合格/精英 | **外部指标规则** 决定候选能否存活 |
| **Thinking Evolution** | Mutation 修改一个代码候选；Crossover 结合两个；也可以先交叉再变异 | **LLM** 生成下一代代码，**种群规则** 选择父代 |
| **Adaptive Generation** | 将过去的有效/无效候选及评价/解释写进下一轮提示 | **Prompt 上下文** 变化；不是参数训练 |
| **下游应用** | 筛选后因子送入 LightGBM/Ridge，Qlib 做模拟回测 | 验证预测和组合效果，非模型自我再训练 |

**Mutation / Crossover 并不是该论文发明的遗传算子**。比简单公式模板更特别的是 **LLM 对 Python 代码进行有金融语义的修改和组合**。原文：[§3.3–3.6](https://arxiv.org/html/2511.18850#S3)，[Appendix A](https://arxiv.org/html/2511.18850#A1)。

## 4. 作者实际声称的贡献 VS 我们可以确认的技术特色

| 项目 | 作者的表述/技术特色 | 边界与依据 |
|---|---|---|
| **Cognitive Alpha Mining 概念** | 作者称提出新的认知式 Alpha 挖掘方向 | 属**作者声明**，不等于独立确认此前无人使用相似框架；[§1](https://arxiv.org/html/2511.18850#S1) |
| **CogAlpha 完整系统** | “七层领域 Agent + 多 Agent 质量审查 + 代码级 Thinking Evolution” 的具体组织 | **可核实的系统实现机制**；不过 LLM 演化编程、遗传算子及 Agent 反馈均有更早相关工作 |
| **跨市场实验** | 作者在中国内地、香港、美国股票集上报告更强的预测与回测表现 | 是该框架的**实验支持**，不能直接推广为实盘盈利证明 |
| **代码级表示与进化** | 不拘泥于预定义符号公式算子，直接生成/改造 Python 程序 | 相对公式搜索有**表示空间差异**，但不能单独声称首创 LLM 进化代码；[§2](https://arxiv.org/html/2511.18850#S2) |

**相邻前作提示**：论文 Related Work 讨论 AlphaAgent、AlphaJungle、RD-Agent-Quant 等因子研究及 FunSearch、AlphaEvolve 等 LLM 进化式程序搜索。因此准确的概括是**金融任务中的具体多组件集成及检验**，而不是“变异、交叉、多 Agent 首次发明”。

## 5. 实验成功点：只保留能说明系统价值的数字

- 主实验：CSI300，预测未来 10 个交易日收益；训练 2011–2019、验证 2020、测试 2021–2024；另覆盖 CSI500、S&P500、HSI、HSCI 等。
- 作者报告主 CSI300/10 日结果：**IC 0.0591、AER 16.39%、IR 1.8999**。虽然大部分指标领先，但 Random Forest 的 **RankICIR 0.4385 > CogAlpha 0.4350**，不能写成全部指标均第一。
- 消融采用**逐步增加组件**：基础 Agent → +E 进化 → +A 自适应反馈 → +G 多样化提示 → +H 七层专业 Agent，AER **7.89% → 8.08% → 8.25% → 12.45% → 16.39%**。所以可以说完整组合在该实验中表现更强，**不能推断每个模块在任何情形下都有独立正增益**。
- Qlib top-50/drop-5 按**每日**检查排名，最多替换 5 只，作者纳入买卖费用；**10 日预测目标并非 10 日调仓**。
- **所有数值是论文的回测报告，不是我们独立复现或实盘**；[§4](https://arxiv.org/html/2511.18850#S4)、[Appendix B](https://arxiv.org/html/2511.18850#A2)。

## 6. 客观局限与尚未核实的疑问

**作者明确陈述的限制**：研究依赖 Qlib 模拟而非实盘、LLM 随机性及随数据规模增加的计算压力；附录 B.6 指出主结果来自**一次完整因子挖掘运行**，而非多种子均值。

**研究者合理质疑（尚不能说论文已经犯错）**：

1. **反复试验选择偏差**：多代试错会不会适应被反复评测的数据，需要更严格滚动样本外与多随机种子。
2. **数据可知时点与交易时点**：用当日收盘价/成交量形成因子，不能直接当日开盘成交；已有未来信息单元测试不自动证明所有时间戳都正确对齐。
3. **因子同质化**：21 个角色是否真带来独立有效 Alpha，需要输出相关性、结构多样性、边际贡献和固定生成成本对照。
4. **经验能力层级**：它把当轮成功/失败案例写入 Prompt，但未证明长期跨任务知识库、参数更新或自行修改搜索策略。
5. **效率口径**：论文报告每个因子 5–9 秒、一代约 1 小时；对照需要相同调用/算力预算，不能单以最高分判优。

**阅读结论**：CogAlpha 对我们最重要的是 **专业角色引导的代码级进化 + 外部质量与指标筛选 + Prompt 反馈**，不是“自我训练了新的金融 LLM”。目前的客观边界和候选疑问以原文实际报告为准。

## 7. 对跨论文 Delta 的轻量映射

- D001（嵌套质量审查/环境反馈）：**变体**——CogAlpha 的进化子代反复质检、评分，Prompt 回灌当代好坏案例，未见 P001 式 Writer/Reviewer 的完全同形循环。
- D002（WorldQuant 101 结构化公式 KB）：**不同，不判定为同一机制**——CogAlpha 用主题 Prompt 和代码级探索，并未采用 P001 的 WQ101 检索 KB。
- D003（成功经验的长期 Main KB）：**不同**——CogAlpha 的候选种群与 Prompt 案例不等于明确的跨任务检索 KB。
- D004（多 Agent 角色分工）：**变体**——CogAlpha 的 21 个专门生成 Agent + 四种质量角色，与 P001 的 Writer/Judge/Reviewer 分工粒度不同。
- D005（样本外验证）：**类似评价范式，细节不同**——CogAlpha 用多市场 Qlib（含费用），但主要报告单次挖掘的结果。
- [D006](../../knowledge/deltas/D006_domain_guidance.md)：**项目新机制**，不同领域角色 + 五类提示多样化。
- [D007](../../knowledge/deltas/D007_code_evolution.md)：**项目新机制**，代码级进化和种群选择。
