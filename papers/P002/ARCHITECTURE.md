# P002｜CogAlpha：架构、作者贡献与已审批的特化评价

[一页架构图](README.md) · [原文与核验范围](PAPER.md) · [已讨论的特化研究疑问](IDEAS.md)

## 论文在做什么

**21 个金融主题 Agent + 五类提示引导 → 生成 Python 因子 → 质量审查和预测指标选择 → 代码变异/交叉与精英保留 → 成败案例进入下一轮 Prompt。**

它生成和改进**因子代码**，而不是更新基础 LLM 权重；因子供下游预测器和 Qlib 模拟回测。专业生成 Agent 是同类 LLM 的不同金融任务 Prompt，并非训练 21 个金融模型。

## 已获研究者审批的特色贡献（2026-10-21）

**金融专业分工 + 多样化 Prompt 的结构化搜索**。作者把因子研究划分成七组、共 21 个金融主题 Agent，各组分别探索特定金融假设；每个方向再用五种 Guidance（light / moderate / creative / divergent / concrete）拓展表达和思考方向，以期覆盖更广的候选因子空间。

**相对已读 P001 的具体区别**：P001 用 WorldQuant 101 已知公式的**检索先验**指导 Writer；CogAlpha 用金融研究主题的**角色 Prompt + 多样化引导**探索候选。两者都是引导搜索，但先验来自不同载体、生成控制方式不同。

**审批准确含义**：研究者认可这是 **P002 值得记录的特色设计与项目级机制差异**；不表示已核实“全球学术首次提出多 Agent/提示多样化”，也不保证所有 21 个 Agent 都贡献独立 Alpha。

**原文**：[§3.1 Seven-Level Agent Hierarchy，§3.2 Diversified Guidance](https://arxiv.org/html/2511.18850#S3)；[附录 A](https://arxiv.org/html/2511.18850#A1)。

## 已获研究者审批的特化风险假设（未被实验确证）

**固定专业分工可能造成“表面多样、实质同质化”。** 即使不同 Agent 从趋势、量价、风险等角度独立生成不同 Python 代码，最终因子输出仍可能高度相关、携带重复预测信息。**候选数量更多 ≠ 独立新增 Alpha 更多**。

此疑问特别针对 CogAlpha 的**预置 21 主题 + 多样化生成**设计，不是泛泛的“量化都会过拟合”。

**如何检验**：在相同 LLM 生成预算下，比较主题之间的因子输出相关性/结构多样性、去重后真正独立有效因子数量，以及新增因子对样本外预测的**边际贡献**。论文的逐步叠加消融报告全系统改善，却不足以单独证实每组主题都增加了独立预测信息。

**审批准确含义**：研究者认可**保留为待验证的特化风险**；不能写成论文已经发生同质化或作者没有做任何去重。

## 核心结果与证据边界（原文事实，不作为创新/缺点候选）

- **主实验**：CSI300，10 日收益预测标签；训练 2011–2019、验证 2020、测试 2021–2024，另涵盖 CSI500、S&P500、HSI、HSCI。
- **作者报告**：IC **0.0591**、AER **16.39%**、IR **1.8999**；RandomForest RankICIR **0.4385** 高于 CogAlpha **0.4350**，因此不能说所有指标都最优。
- **逐步消融**：依次加入进化、反馈、多样化引导、七层专业分工，AER 从 **7.89%** 提升到 **16.39%**；该实验是逐步叠加，不等于每个模块的独立因果贡献或多种子稳健性。
- **回测口径**：Qlib top-50/drop-5 每日调仓检查（最多换 5 只），作者计入费用；10 日收益预测标签并非 10 日调仓。仅作者模拟回测，未独立复现。
- **作者自己报告的限制**：非实盘验证、LLM 随机性、计算资源消耗；这些属于证据边界，**目前未获单列为本论文特化缺点的审批**。

依据：[论文 §4 与附录 B](https://arxiv.org/html/2511.18850#S4)。
