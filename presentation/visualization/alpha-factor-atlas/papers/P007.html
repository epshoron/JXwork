01 / HOW IT RUNS

系统怎么运行？

从输入走到真正可检查的输出；下方虚线提醒这不是单向流水线，而是存在反馈。

反馈到底更新什么：训练奖励反馈给生成策略；训练结束后用新模型继续产生因子，供下游预测与回测检验
02 / MAKE IT CONCRETE

用一个例子理解

若按某因子值分成五组，收益最高的可能是第二组、最低的是第四组。TMB 取这两个组收益均值之差，而不要求它们是因子大小两端。

03 / IMPORTANT MECHANISMS

三个关键点

D012 · ③生成

金融文献 → 可执行公式

LEGO 从金融标题/摘要获取假设线索，和受限行情变量、公式 DSL 组合，指导 LLM 构造可执行 Alpha。

D013 · ⑤评价

TMB 单因子奖励

按因子值给股票分组，取未来收益最高与最低两组的差值；再结合公式执行和时间合法性。

LLM 训练 · 实心

DAPO 参数级训练

奖励直接用于更新公式生成 LLM 的策略权重；与 P002 的外部代码进化不是同一更新层级。

04 / COMPARE

和其他论文区别在哪？

P005 训练多轮工具轨迹最终因子池；P007 着重单公式的收益分组奖励。

实际被更新的对象：生成因子的 LLM 策略参数（DAPO）；不是只改变 Prompt 或公式池
05 / EVIDENCE BOUNDARY

哪些结论需要保留边界？

最大/最小分组差在有限样本中可能受偶然极值影响，但这只是低置信度待验证风险。原始 PDF 中部分实验表仍需逐页复核。
