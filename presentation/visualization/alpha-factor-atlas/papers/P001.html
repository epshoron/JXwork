01 / HOW IT RUNS

系统怎么运行？

从输入走到真正可检查的输出；下方虚线提醒这不是单向流水线，而是存在反馈。

反馈到底更新什么：Judge 不合格 → 返回 Writer；回测不佳 → Reviewer 指导 Writer 再改；成功因子进入 Main KB
02 / MAKE IT CONCRETE

用一个例子理解

把 WorldQuant 101 当作公式结构参考书；Writer 先写候选，Judge 检查是否合理，回测表现不佳再由 Reviewer 给出改进反馈。

03 / IMPORTANT MECHANISMS

三个关键点

D002 · ③生成

经典公式结构先验

101 Alpha KB 给 Writer 提供可参考的已知公式结构；并不是直接复制公式，也不代表 LLM 不参与生成。

反馈 · 机制位置

两层不同问题的反馈

内循环判断“写得是否合理”，外循环判断“市场统计表现如何”；二者都可能让 Writer 重写候选。

⑥经验积累 · 实现差异

成功经验复用

通过 KB Updater 将通过标准的因子写入 Main KB，下一项研究可以重新检索它们。
