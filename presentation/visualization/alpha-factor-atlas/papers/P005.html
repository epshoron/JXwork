01 / HOW IT RUNS

系统怎么运行？

从输入走到真正可检查的输出；下方虚线提醒这不是单向流水线，而是存在反馈。

反馈到底更新什么：搜索中：当前池状态反馈下一轮；离线训练：最终池的未来窗口评价 → GRPO 更新 LLM 策略参数
02 / MAKE IT CONCRETE

用一个例子理解

一个新因子自身 IC 很高，但与池里已有因子高度重复，就未必值得加入。Pool Updater 比较加入/替换后整个因子池是否更好，而不只看个体。

03 / IMPORTANT MECHANISMS

三个关键点

D016 · ⑥筛选

池级边际增删

候选加入或替换以后，考察它对整个因子池组合分数的增量，决定接纳、拒绝或替换。

反馈 · 核心控制

多轮真实工具轨迹

LLM 能看到近期尝试结果和当前因子池；一条轨迹包含多次生成、评价和池状态变化。

LLM 训练 · 实心

GRPO 真正训练 LLM

历史离线训练基于多条完整探索轨迹最终因子池的奖励，更新生成模型的搜索策略参数。

04 / COMPARE

和其他论文区别在哪？

P007 奖励单条公式的合法性和 TMB；P008 奖励围绕种子连续改进的多目标轨迹；P005 奖励最终形成的整池。

实际被更新的对象：在线/测试日改变因子池；离线 GRPO 真正更新生成 LLM 策略权重
05 / EVIDENCE BOUNDARY

哪些结论需要保留边界？

测试日因子池会变化，不代表每天重新训练模型。论文中的单轮 GRPO 对照同样使用 RL，不能拿它估计“完全不用 GRPO”的增益。
