AI Agent 量化因子挖掘 · 离线机制地图（v1.0）

使用方式：
1. 解压整个 ZIP 文件（不要仅单独抽取 index.html）。
2. 双击 index.html，用 Chrome / Edge / Safari 等浏览器打开。
3. 左侧最多选择三篇论文，点击右侧“查看 P00X 机制详解”进入独立页面。
4. 独立页面通过顶部“主地图”或底部按钮返回；P001–P010 之间可顺序切换。

文件组织：
- index.html：统一原始六环节骨架、三篇论文对照和机制摘要。
- papers/P001.html ～ papers/P010.html：十篇论文机制说明与自绘流程。
- assets/detail.css：详情页公共样式。

说明：
- 所有页面和图表完全离线可用，不依赖 CDN 或在线脚本。
- 原论文/项目仓库等“来源”按钮是外部网页链接，访问时需要联网。
- 主图从已确认的 UI v0.3 保留，阶段布局与 SVG 内容未被修改。
