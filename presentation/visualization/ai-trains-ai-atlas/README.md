## 用法

- **离线优先**：保存整个 `visualization/ai-trains-ai-atlas/` 文件夹，并同时保留同级 `visualization/alpha-factor-atlas/assets/detail.css`（六篇详情页共用 P 系列已认可的样式）。在浏览器打开本目录的 `index.html`。**只下载一个 HTML 文件时**，首页的统一图和对照表仍可独立显示，但六篇独立页以及返回 P 系列 Atlas 的相对链接需对应目录文件一起下载。
- **GitHub 不是 HTML 网页托管器**：在 GitHub 的 blob 页面打开 `.html` 一般显示源码，不会按网页交互执行。需要在本地 Edge/Chrome 打开或由获授权的网页托管服务提供静态页面。不要为了方便把私有研究或 PDF 发布到公开 GitHub Pages。
- 左侧最多选三篇，中间显示关键机制落点，右侧解释；点论文详情进入每篇自绘流程图与原文/项目 PDF。
- T002 / T006 默认同时选中，突出 **通用 Prompt 演化算法 vs 科学研究 Agent 评测平台** 的真实差异。
- ● 关键机制、○ 实现差异均不代表学术首创；任何创新、特化不足与 TD 审批仍沿用既有档案，Atlas 只是研究展示层。
