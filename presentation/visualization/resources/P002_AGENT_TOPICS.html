本页是 P002 工程问题主表 中“金融专题 Agent”一项的补充阅读入口，不是第二张研究表格。分类及模板文件名依据作者公开的 Seven-Level Agent Hierarchy README 核对。

实际怎么实现

所谓 21 个 Agent，是21 种金融研究专题 Prompt，并非 21 个分别微调的金融大模型。各角色的差异主要来自两部分：Agent-Specific Intro（角色/研究任务）与 Agent-Specific Factor Design Guidance（因子构造指引）；共享系统提示、代码约束、库规则和输出格式。已有有效/无效因子时，还可以把成败分析插入生成 Prompt；部分 Guidance 可先经过五种风格之一改写。详见作者 Prompt 组装说明。

七层分类与具体 Prompt

I｜市场结构与周期（2）：市场周期 Market Cycle、波动状态 Volatility Regime。关注市场周期与波动状态变化。

II｜极端风险（2）：崩盘预警 Crash Predictor、尾部风险 Tail Risk。关注突发下跌与尾部脆弱性。

III｜量价关系（4）：流动性 Liquidity、订单失衡 Order Imbalance、量价协同 Price-Volume Coherence、成交量结构 Volume Structure。关注成交量、订单与价格的关系。

IV｜价格与波动行为（5）：日频趋势 Daily Trend、滞后响应 Lag Response、区间波动 Range Vol、反转 Reversal、波动非对称 Vol Asymmetry。关注趋势、反转、价格区间及非对称性。

V｜多尺度复杂性（3）：回撤 Drawdown、分形 Fractal、羊群行为 Herding。研究不同时间窗口下的复杂结构与群体行为。

VI｜稳定性与状态门控（2）：状态门控 Regime Gating、稳定性 Stability。研究不同市场状态下哪些信号更稳健。

VII｜几何形态与融合（3）：K线形态 Bar Shape、组合因子 Composite、创造性设计 Creative。关注K线形态与组合、变换式因子设计。
