# synthesis / 经确认的综合研究成果

此目录目前保留 `RESEARCH_LENSES.md`，作为**暂定研究提问框架**，不是已验证的分类地图或逐篇笔记。

**写入规则（2026-10-21 更新）：**

- 日常论文理解、原文核验、质疑、比较与观点修正**先在 LLM 对话内完成**，不要边读边建立 GitHub 笔记/比较表/阶段性结论。
- **等研读讨论结束、LLM 内已整理出总结且用户要求或确认归档**后，再把精炼的、标注原始证据和不确定性的**正式综合总结**写入这里或用户指定的位置。
- 可能的最终成果包括方法比较、工程路线、反馈机制/RSI 辨析及面向导师的讨论提纲，但**不提前创建空壳文件或未经证实的完整分类树**。
- 无论何时都不得写入公司内部信息、凭据或未经授权的论文原文。
