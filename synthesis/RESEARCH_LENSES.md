# 当前研究框架：三个互补的问题视角（工作假设）

**日期：2026-10-21**  
**状态：阶段一阅读时的提问辅助，不是经系统论文比较验证的分类地图，更不是项目三阶段本身**

## 为什么不称为“三大流派”

质量控制、经验学习、推理协作分别关心因子可靠性、从反馈中改进和多视角协同；它们**可以共存在同一系统**。不要把方法（GP/RL/LLM）、组件（多 Agent/记忆/工具）、自主程度和研究目标混为互斥类别。

| 视角 | 在研读对话里需要追问什么 | 候选机制线索（需原文核对） |
|---|---|---|
| **质量控制** | 有效性、创新性、可解释性和稳健性如何保证？怎样减轻同质化、泄漏和过拟合？ | 金融语义约束、公式/AST 去重、复杂度惩罚、样本外回测 |
| **经验学习** | 历史实验怎样具体影响后续探索？反馈更新的是提示、种群、记忆、策略还是模型权重？ | 反馈反思、跨轮记忆、演化、RL、训练 |
| **推理协作** | 由谁提出、审查、质疑、修复和裁决候选？ | Agent 分工、互评、辩论、专家路由、人机协作 |

- 三者**不是能力递进阶段**，也不是穷尽全部研究问题。
- 多 Agent 不等于标准 MoE；辩论不等于对抗训练；反馈或长期记忆不自动等于参数更新/严格 RSI。
- 如新论文无法归入以上视角，应修改问题框架，而不是硬贴标签。

## 与项目三阶段顺序的关系

**当前研究阶段一：完整读懂论文**，三个视角只帮助理解作者实际做了什么；先把输入输出、核心方法、反馈与实验复述准确。**阶段二**才在足够多的论文已被理解后，结合原始证据整理创新与缺点并做跨论文比较。**阶段三**才在积累充分后，将创新与缺点的互补性有机结合为我们自己的研究假设。详见 `../RESEARCH_PLAN.md`。三视角属于**可组合的问题视角**，三阶段属于**先后顺序**，不可相互替代。

## 使用方式（仅在 LLM 对话内）

1. 找原始论文；在 `papers/INDEX.md` 最小认领去重。
2. 在 LLM 对话中审视输入/输出、核心机制、反馈路径、验证设计及证据。
3. 在阶段一对话里先确保论文**整体机制和原文实验已经理解**，再讨论视角适用性；不提前做跨论文创新/缺点整合，**不逐篇提交标签表、读书笔记或阶段性研究报告**。
4. **等用户与 LLM 结束研读、确认总结后**，再整理为有来源支持的 `synthesis/` 正式成果。

**注意**：本文件只保存既定研究问题，不表示已验证任何具体论文的实证效果。
