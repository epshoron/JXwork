# 方向 A｜论文技术深读主表

**启用日期：2026-10-23；首篇 P001。**

这是研究者明确要求的新“技术级研读”层，目标不是再写一页概览，而是从论文全文出发核实**数据、算法、代码、全部计算口径、实验、可复现性**，并随着 P001–P010 的重读持续加字段、回填所有论文。

- **[统一论文主表 MATRIX.csv](MATRIX.csv)**：一篇一行，每个稳定字段一个列；所有十篇论文使用同一套字段。
- **[字段字典 SCHEMA.csv](SCHEMA.csv)** 和 [字段维护规则](SCHEMA.md)：字段 ID、定义、核查目标、版本 v0.1。
- **[P001 深度技术核验表](P001.md)**：首篇已建立，填入仅来自期刊摘要或作者 README 的已核事实；未验证细节明确留下“未核”。
- 后续重读 P002–P010 以同一字段表建立逐篇深度核验记录；发现字段缺失先同步增加，不能给特定论文独占私有字段。

## 与已有研究档案的区分

原 `papers/P00X/`、`knowledge/deltas/D00X` 是已审研究骨架、成果与机制库，全部保留。这里是**技术事实审计表**，容纳细到代码行、计算公式、时间戳与测试验证的内容；不能用新表绕过研究者对创新、特化缺点和新机制 Delta 的逐项审批。

**原则：每个具体结论都有原始证据；未查就是未核；不能用通用常识补论文；最终“读懂”要求能够解释并定位原文/源码，关键数值可以算出来。**
