## 证据状态

- **期刊摘要已核**：只证明摘要/Highlights 层面的论断，不等于全文读完。
- **作者 README 已核**：是作者公开说明，而非代码执行或指标复算。
- **原文页码/公式已核**：实际打开全文或附录并按具体位置核对。
- **代码已核**：定位到固定 commit + 函数/行号，跟踪输入输出和调用关系。
- **计算已复核**：写出完整公式、时间/张量轴和手算或程序复算证据。
- **未核 / 不适用 / 无资料**：三者严格区分；没有证据不能填“无”。

## 修订原则

1. 遇到新问题，先看能否用现有字段准确记录；若不能，添加**原子新字段**，指定稳定 ID、定义、核验完成标准。
2. 所有 P001–P010 都增同字段，先空后补；**不能仅改 P001**。不得因为某篇没有某算法就删掉通用字段，应该填“不适用（有证据）”。
3. 每个重要数值要有**定义、分母、时间粒度、数据来源、源码/公式位置**。尤其重叠五日收益与年化 Sharpe，禁止以常识脑补。
4. `MATRIX.csv` 是快速检索/机器维护主表；单篇 `P00X.md` 是可核查的细节展开。重复结论互相链接，不把 GitHub 表格当成运行过的回测。
5. 阅读事实可随证据补充；学术创新评价、独立不足、Delta 等仍按现有 JXwork 审批与跨方向去重规则，不在本表偷渡未经批准的判断。
6. 仓库是 Public：不放入公司内部资料、授权受限的论文 PDF、密钥或私人数据。
