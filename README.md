## 研究目标

关注 **LLM / Agent 驱动的量化因子发现（LLM/Agent-based Alpha Discovery）**，尤其关注 Agent 能否自主提出因子、调用工具验证、根据反馈调整后续探索，以及是否有更深层的自我改进机制。

这是一个**待研究的问题**，不是预设完整系统已经可行。另一条相关线索为 AI 自我改进（Self-Improvement / RSI）；二者关系需要通过原始论文辨析，不直接等同。

## 工作方式

**先找和读原始论文 → 逐篇记证据 → 比较不同方法 → 逐步长出研究地图 → 形成可讨论的技术路线。**

不提前宣布“已经找到了完整、互斥的行业分类”。知乎等二手综述可以提供线索，但每项方法要追溯到可靠的原始来源。
