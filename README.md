# JXwork · AI 因子研究工作区

> **当前阶段：在 LLM 对话中检索、研读与讨论原始论文（2026-10-21）**  
> **仓库用途：研究规范、公开论文认领/去重、研读结束后确认的综合总结。**

## 研究方向

研究 **LLM / Agent 驱动的量化因子发现**：因子生成与搜索、验证反馈、自主迭代、Agent 协作，以及它们与自我改进 / RSI 的真正关系。先研究原始论文，不预设完整或互斥的技术流派。

当前暂用 **质量控制、经验学习、推理协作** 三个互补视角提问；它们可以并存，也允许随研究修正，详见 [synthesis/RESEARCH_LENSES.md](synthesis/RESEARCH_LENSES.md)。

## 工作流（2026-10-21 更新）

**GitHub 轻量认领去重 → 在 LLM 对话里研读和讨论 → 人机核对与形成总结 → 研读阶段结束后再写正式综合成果到 GitHub。**

- 开始处理某篇论文时，仅在 [papers/INDEX.md](papers/INDEX.md) 登记**标题、权威原文链接、S5/S6 认领人和最小状态**，让并行窗口避免重复。
- **研读过程中不创建逐篇读书笔记、笔记模板、阶段性论文总结或论文分析日志**。理解、质疑、修正和讨论都留在该窗口的 LLM 对话中。
- **只有在与用户完成研读讨论、形成可确认的结论之后**，才根据用户要求将精炼研究总结写入 [synthesis/](synthesis/)；不要把过程中未经确认的推论直接固化为仓库文档。
- 更新公共 Markdown 前读最新版本并处理提交冲突；不要读取 S5/S6 另一个窗口的聊天记录来做去重。
- `CHANGELOG.md` 仅记录**研究规范/架构变更，以及最终总结的发布**，不再作为逐篇研读过程日志。
