# 方向 B｜AI 如何训练 AI（AI trains AI）

> **状态：研究方向已获研究者批准，目录初始化（2026-10-22）**。尚未认领论文，也未确认该方向的技术分类、创新点或研究方案。

## 研究问题

关注 **AI 参与训练其他 AI（或同一模型自身）的过程**：谁生成训练信号、数据或反馈？谁被训练？哪些对象实际发生改变？是否有可验证的能力提升、成本收益及稳定性证据？

可用来**寻找论文**的线索包括：模型作为教师或标注/数据生成者、合成训练数据、自训练、AI 评价/奖励与反馈、RL/后训练、自动化训练流程等。**这些只是搜索线索，不是已确认的学术分类，也不预设都属于严格递归自我改进（RSI）。**

研究中尤其区分：模型仅改写输出/Prompt，与**真正发生训练或参数/训练数据/奖励器更新**的机制；以及方法提出的效果与实验真正证明的效果。
