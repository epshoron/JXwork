## 多 Agent 并行认领约定

- **一个 Agent 一次只认领一篇 CR 研报**；多个 Agent 可同时处理不同研报，不等待彼此，且不需要排队到 C 学术论文之后。
- 研报作为非学术论文，先说明来源价值，研究者**可以按批批准收录候选**。获批后仍每个 Agent 各自领一篇，明确券商、标题、发布日期与可见原文范围。
- 认领当轮**建立该篇最小 README.md、PAPER.md，并同步本 INDEX**；只有摘要就如实写摘要，不写成读完全文。
- 写共享 INDEX 前刷新最新 SHA，遇冲突重读并避开占号；绝不覆盖其他 Agent 的研报记录。每个 Agent 自己同步自己负责的 MD 与 INDEX，完成这篇本轮工作后才再认领。

## 轻量使用说明

- 从 **CR001** 编起，不和 C 编号混用；正式收录后按需要建 `CR00X/README.md`、`PAPER.md`，不强制生成空白研究文件。
- 优先记录分钟数据字段、因子聚合方式、计算时点、回测口径、可获取原文的范围。
- 完整付费研报不要擅自上传；若只有公开摘要，必须如实注明，不冒充已核全文。
- 正式新增或更正报告档案时同步本表。真正机制创新等仍须拿证据讨论认可。
