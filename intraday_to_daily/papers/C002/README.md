# C002｜Investor clientele and intraday patterns in the cross section of stock returns

> **方向 C｜已认领，阶段一初读（2026-10-27）**。原文为开放获取的同行评议论文；已核对摘要、§3 数据与方法、§4 部分结果。不是完成全文精读，也**不是已复现的日频 Alpha 因子**。

## 一句话定位

研究股票**同一日内半小时区间的跨日收益延续/反转**：某只股票在今日某时段的表现，与它未来交易日同一时段的收益是否有关？对比英国、巴西与中国 A/B/H 股。论文并非直接从分钟 OHLCV 输出「明日收盘收益预测分数」。

## 原文方法骨架

```mermaid
flowchart LR
    A["逐笔成交与买卖报价"] --> B["划分半小时区间"]
    B --> C["计算各区间收益"]
    C --> D["同一时段跨日滞后"]
    D --> E["横截面回归与分组"]
    E --> F["统计与组合收益检验"]
```

- **数据**：Bloomberg 高频交易及报价数据，CSMAR 提供中国股票类别；主样本 2016-06-01 至 2019-03-01。中国股票交易日分为 **8 个半小时**（9:30–11:30、13:00–15:00）。
- **计算对象**：作者定义成交价区间收益 `R` 与买卖报价中点收益 `MPR`；主要回归采用 **MPR**，旨在减少 bid–ask bounce。
- **跨日比较**：对同一半小时区间使用前 1–40 个交易日的对应时段收益；回归系数及 Fama–MacBeth t 统计量检验跨股票关系；另以股票横截面十分位分组检查经济效果。
- **作者报告**：英、巴市场的对应时段动量更明显；中国 A 股整体相对较弱，作者进一步分析投资者构成、涨跌停和 T+1 规则。不能等同于已证实中国市场可直接交易的日频因子。

## 对方向 C 的关联与限制

**能够借鉴的表示方式**（下面是研究视角转换，而非论文原样交付）：

- 对每只股票每天得到 `[上午四段收益, 下午四段收益]`，形成**股票 × 日期 × 8 个时段值**；也可以在日频维度继续加入同一时段的历史滞后。
- 注意计算时点：完整八段数据在当日收盘后才全部可见，不能用来在当日开盘前预测。
- **关键限制**：原文使用 bid/ask 报价中点，而普通 1/5 分钟 OHLCV 没有报价中点；若未来使用 K 线近似，需要定义不同计算口径并重新检验，不能称作原文复现。
- 原文主要检验未来**同一日内时段**收益的可预测性，而非次日 close-to-close 日度 RankIC；若要改为日频选股需要独立检验标签、时点和成本。
