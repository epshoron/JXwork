# C001｜Good Volatility, Bad Volatility, and the Cross Section of Stock Returns

> 方向 C · 客观金融知识归档（2026-10-27）。基于作者 **2018-11-15 版本全文**和出版社正式题录核查；正式刊发于 *Journal of Financial and Quantitative Analysis* 55(3), 751–781 (2020)。未独立复现，未逐字核对最终刊发版全文。不包含面向 Agent 的研究建议、指令或自拟 Idea。

## 研究问题与原文观点

- **研究对象**：一只股票的日内价格变动方向是否携带超出总波动率的信息？正收益对应的日内波动（作者称 good volatility）与负收益对应的日内波动（bad volatility）之相对差异，是否与未来股票横截面收益有关？
- **作者的经验假设**：正负方向的高频价格冲击可能受到不同定价；论文基于资产定价与市场微观结构文献讨论可能的**投资者过度反应、套利限制**，这些是解释性假设，不是单独证明的因果事实。
- **名称说明**：“good/bad”仅按高频收益的正负号区分，不是对公司基本面消息作正负分类。

### 日内 5 分钟 → 每只股票每日的统计量

作者设第 `j` 段日内对数收益为 `r_{i,d,j} = log(P_{i,d,j}) − log(P_{i,d,j−1})`，每天采用美国正常交易时段 **78 个五分钟收益**。

- **日度实现方差**：`RV = Σ_j r_j²`。
- **正半方差**：`RV⁺ = Σ_j r_j² · 1(r_j > 0)`。
- **负半方差**：`RV⁻ = Σ_j r_j² · 1(r_j < 0)`。
- **关系**：`RV = RV⁺ + RV⁻`，正负半方差分别只计入对应符号的五分钟收益。
- **带符号差值**：`SJ = RV⁺ − RV⁻`。
- **相对带符号跳跃变动（RSJ）**：`RSJ = (RV⁺ − RV⁻) / (RV⁺ + RV⁻)`，当总实现方差为正时，其值介于 −1 与 1 之间。

**符号含义**：RSJ 正，表示样本内正向五分钟收益贡献的平方和更大；RSJ 负则相反。作者从高频极限理论解释 SJ 的跳跃含义；有限频率计算的 RSJ 不能直接等同于已逐次定位、确定方向的真实价格跳跃。

### 日度统计量 → 论文实际的周度预测实验

作者把最近 **5 个交易日的日度 RSJ 求平均**形成周度 RSJ（另外计算 RVOL、实现偏度 RSK、实现峰度 RKT 作为对照）。**不是将一周所有五分钟收益先合并，再重新计算一个比值。**

每周二收集此前一周的度量，按股票 RSJ 分为五组，检验随后一周的持有收益；同时做不同权重分组、双重分组、Fama–MacBeth 横截面回归及其他控制检验。

## 实际数据与口径

- **高频字段**：美国 TAQ 的日内逐笔**成交价格**，提取 9:30–16:00 时间段，并以 5 分钟采样；不需要逐笔委托方向或真实订单簿才能计算上述平方收益统计量。
- **股票与样本**：NYSE、AMEX、NASDAQ 普通股；按股票类型和价格筛选。作者稿样本为 **1993-01-04 至 2013-12-31**，与 CRSP 数据匹配，覆盖 19,896 个不同证券标识（这是匹配总量，不代表所有证券均进入最终统计样本）。
- **辅助数据**：CRSP 日/月收益、退市收益、股本、成交量与公司特征；Fama–French–Carhart 四因子用于调整组合表现。
- **计算可见时间**：某交易日完整日内统计量到该日 16:00 时段结束后才可确定；每周二组合按此前已完成的收益数据形成。

## 作者稿中的主要实证结果（美国股市，不是 A 股）

- **RSJ 与随后一周收益负相关**：RSJ 最低组的随后周收益高于最高组。作者稿表 3：市值加权“最高组减最低组”为 **−29.35 bp/周，t = −5.83**；等价的最低组减最高组为 **+29.35 bp/周**。这是历史模拟的组间差异，不是保证可交易净收益。
- **与偏度的联系**：单独按实现偏度（RSK）分组时也呈负向关联；但进一步控制 RSJ 后，RSK 的条件关联方向发生反转，而 RSJ 的关联仍保留。这一结论属于论文特定样本和设定。
- **其他指标非同样稳健**：作者稿中按 RVOL 分组的市值加权最高减最低组为 **+17.19 bp/周，t = 1.29**，未呈现同样的统计强度。
- **作者讨论的机制性证据**：RSJ 相关收益差异在较小、价格更不稳定及流动性较差的股票中更明显；作者解释与投资者过度反应、套利受限一致，但不是因果识别结论。

## 边界

1. **原论文的主要预测和组合频率是周度**：其中包含严格定义的**每日分钟聚合变量**；并未直接证明单日 RSJ 能预测下一交易日的横截面收益。
2. **股票市场是美国**：原始实证不能直接转述为中国 A 股已有相同效应。
3. **成交价采样与微观结构噪声**：作者选择 5 分钟频率作折中，并报告其他采样方案的稳健性；不等于已证明任何分钟频率均相同。
4. **RSJ = 0 或 RV = 0 等边界数据如何实际清洗**，需按原文附录与代码核对，本归档不臆造处理方式。
5. 原文研究的变量间关系与作者解释分开陈述；不推导新的因子方案，也不对下游金融专题 Agent 下达探索指令。
